# 테스트 명세 — 시흥 투어패스

검증 범위·방법·판정 기준을 관리한다. 제품의 완료 기준은 [요구사항](../func-specs/01-common.md), 구현 구조와 남은 작업은 [구현 계획](../tech-specs/01-plan.md)을 따른다. 테스트 실행 명령은 [루트 README](../../README.md#테스트)에서 관리한다.

## 검증 전략

CI는 PR과 main 반영 시 실행하며 같은 브랜치의 이전 실행은 취소한다. 서로 다른 초기 데이터가 필요한 API·화면·관광 검사는 격리된 DB에서 유지한다.

테스트는 정책 경계·권한·저장 결과·사용자 조작을 검증하며, 단순 문구·장식 스타일·데이터의 고정 개수는 고정하지 않는다.

자동 검사의 실행 환경·명령은 [README 테스트](../../README.md#테스트)를 따른다. 자료 최신성 검토와 사용자 검증은 자동 검사 통과 여부와 별도로 확인한다.

## 화면 검증

일반 화면 테스트와 캡처는 데스크톱 가로 16:9(`1920×1080` CSS px), 모바일 세로 19.6:9(`360×784` CSS px, 높이:너비)를 기본 뷰포트로 통일한다. 크기는 브라우저 UI를 제외한 콘텐츠 영역 기준이다.

가로 넘침·메뉴 겹침·긴 라벨·폼·조작 영역을 확인한다.
