# 평가 기준

제안서·프로젝트 평가에는 아래 기준을 적용한다. 각 평가의 총점은 100점이다.

평가 항목·배점은 유지한다. 이번 기획의 시연 근거는 개인 여행 구성 → 추천 담기 → 방문 기록 → 아카이브 흐름이며, 상세 완료 기준은 [요구사항](../spec.md#검증완료-기준)을 따른다.

## 제안서 평가기준

1. 문제 정의와 지역 연계 근거 (20점)

   - 목표 사용자와 문제(현안)가 구체적인지
   - 조사 근거와 시흥시의 연관성이 있는지
2. 해결방안과 차별성 (15점)

   - 기존 서비스의 한계를 적절하게 분석했는지
   - 의미 있는 개선인지
3. 서비스 설계와 구현 가능성 (25점)

   - 기능(데이터 등)이나 화면의 흐름이 잘 연결되는지
   - 기술/개발 범위에 대한 계획이 현실적인지
4. 추진 계획과 업무 분담 (15점)

   - 일정과 산출물이 명확한지
   - 모든 팀원이 개발에 적절하게 참여하는지
5. 발표 전달력 (25점)

   - 핵심 내용을 시간 내 이해하기 쉽게 설명하고 있는지

## 프로젝트 평가기준

1. 지역 연계성 (20점)
2. 문제 해결성 (20점)
3. 창의성 (20점)
4. 완성도 (20점)
5. 정책 활용 가능성 (20점)
