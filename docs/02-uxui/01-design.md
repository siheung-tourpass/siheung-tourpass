# 디자인 기준 — 시흥 투어패스

[문서 안내](../../README.md#관련-문서) · [요구사항](../01-func/README.md) · [기술 구조](../03-tech/01-architecture.md)

## 공통 규칙

수치·규격은 [토큰](../../frontend/assets/css/tokens.css), 스타일은 [스타일](../../frontend/assets/css/style.css)이 원본이다.

- 초록 강조색·중립 회색 바탕·시스템 한국어 글꼴과 모바일 단일 열 레이아웃을 기본으로 사용한다.
- 불투명 둥근 표면과 짧은 저농도 그림자로 입체감을 표현하며(두꺼운 외곽 그림자·배경 블러 금지), 투명도는 그림자·사진 틴트·모달 배경에만 허용한다.
- 입력은 불투명 중립 표면·명확한 경계, 주요 행동은 강조색 채움, 보조 행동은 흰 표면, 위험 행동은 오류색·문구로 구분한다(색 단독 전달 금지).
- 주요 버튼·입력 높이 52px 이상, 상시 라벨·키보드 포커스, 본문 대비 4.5:1, 입력 경계·포커스 대비 3:1 이상을 유지한다.
- 자동 등장 효과는 금지하며([홈 배경](#홈) 연속 이동만 예외), 모션 감소 설정 시 이동 효과를 끈다.

## 검증

[테스트 명세](../04-test/01-verification.md#화면-검증)에서 관리한다.

## 공통 화면 틀

- 고정 상단 중앙에 프로젝트명, 좌우에 동일 폭 조작 영역(왼쪽은 하위 화면 뒤로가기 전용)을 두며 본문·앵커·포커스 가림을 방지한다.
- 하단 내비게이션과 고정 작업 버튼은 [플로팅 필 탭 바](#플로팅-필-탭-바)를 따르며, 보조 조작 영역은 44px 이상과 실제 체크박스를 사용한다.
- 팝업은 화면 중앙(최대 폭 640px, 좌우 여백 16px, 공통 표면·곡률·배경 음영)에 두며 상단 제목·닫기, 내부 스크롤, Esc·바깥 클릭 닫기, 실행 버튼 포커스 복귀를 제공한다.

## 카드 방향

- 여행 패스·혜택 이용권·상품은 가로형 명함 카드(절취선·분리 구획 없음, 좌측 정보·우측 상태/동작, 좁은 화면은 동작을 아래에 배치, [토큰](../../frontend/assets/css/tokens.css) 공유)를 사용한다.
- 관광지·행사·가맹점·혜택 조건은 기본 `2:3` 세로형 카드(탐색 덱만 고정 비율·내부 스크롤, 상세·폼은 내용에 맞춰 확장)를 사용한다.

## 화면 구성

상단 브랜드(시흥시 BI·프로젝트명, 랜딩·관리자 외 홈·로그인에 시흥시 캐릭터, 기존 투어패스 파비콘/아이콘) → 제목·설명 → 입력·결과 순서로 배치한다. 정상·빈 결과·실패 상태마다 다음 행동을 안내하며 여행 상태는 [저장과 상태 변경](../01-func/02-visitor.md#저장과-상태-변경)을 따른다.

### 역할별 메뉴

| 역할 | 주 메뉴·구성 |
| --- | --- |
| 방문객 | 하단: 홈 → 여행 만들기 → [내 투어패스](#내-투어패스) → [내 여행](#패스-목록표지) → 프로필(설정·로그아웃). ([투어패스 안내](#투어패스-안내) 참고) |
| 관리자 | 홈 → 관광 관리(현황·관광지·개념·관계) → 혜택 관리(상품·가맹점·혜택·이용권) → 통계 → 프로필. |

메뉴 노출·로그인 이동은 [공통 인증](../01-func/01-common.md#공통-화면과-인증)을 따른다.

### 관리자

홈은 자료 수·검토 대기 → 관리·통계 바로가기 → 공개 화면 확인 순서로 배치한다. 관광 관리 목록은 `2:3` 탐색 카드(사진 원본 비율·종류·이름·위치)를 공유하며 검색·종류 필터와 페이지 분할을 제공한다([자료 관리](../01-func/04-admin.md#자료-관리)).

- 관광 관리의 지역·테마·관계는 접힌 보조 메뉴에 둔다.
- 혜택 관리는 상품 카드에 연결 가맹점·혜택을 표시하고 대상 선택 후 편집 폼을 연다.
- 카드 출력은 `관광 관리 → 상세(편집·출력 선택) → 출력 설정(문구·수량, 접힌 QR 주소·인쇄 기준) → 미리보기·인쇄` 순서며, 인쇄 시 탐색·메뉴·폼을 숨기고 [포토카드 규격](../01-func/04-admin.md#관리자-작업과-카드-출력)과 QR 흰 여백을 유지한다.
- 편집 화면은 데스크톱 2열·모바일 1열이며 검색·활성/검토 필터를 제공한다. 비활성화는 영향 안내를 펼친 뒤 실행한다.

### 관광지 피드백

관광지 상세 하단에 만족도·의견·저장·삭제(비로그인은 로그인 링크)를 두고, 통계 메뉴에서는 관광지별 응답 수·평균·점수 분포를 카드로 표시한다.

### 랜딩·로그인

랜딩은 `[홈 배경](#홈) → 소개 → 로그인 → 공개 탐색` 순서다. 로그인은 아이디·비밀번호 폼과 하단 노란 말풍선 아이콘의 `카카오톡으로 로그인` 버튼(미설정 시 비활성, 취소·실패·만료 시 재시도 안내)을 제공한다([공통 인증](../01-func/01-common.md#공통-화면과-인증)).

### 홈

- 랜딩·비관리자 홈 상단 배경은 무작위 공개 관광지(크롭)·행사(원본 비율, 문구 비중첩) `2:3` 카드를 좌측으로 무한 이동시키며 일시정지·모션 감소 시 멈춘다(지연 로딩 제외, 복제본 보조기술 숨김, 사진 출처 팝업은 [이미지 기준](../data-collection/common.md#이미지) 적용).
- 방문객 홈은 새 여행(강조)·제작 중·확정 패스를 전체 클릭 대시보드로 표시하고 제작 중·확정 수와 최근 제작 중 이름을 안내한다.

### 패스 목록·표지

- 내 여행은 사용 완료 기록만 표시한다(진행 중은 내 투어패스, 제작 중은 여행 만들기).
- 패스 목록·상세 표지는 가로형 카드(우측에 첫 사진 카드 이미지 또는 단색, 좌측 불투명 표면에 제목·상태·날짜·동작)를 공유한다.
- 카드 클릭 시 제작 중은 이어 만들기, 확정·완료는 상세로 이동한다. 삭제·사용 완료·제작 중 복귀는 우측 상단 아이콘·확인 팝오버로, 구성·출처 팝오버는 하단 버튼으로 분리한다([공통 화면 틀](#공통-화면-틀) · [이미지 기준](../data-collection/common.md#이미지)).
- 새 여행 만들기는 상품 선택 화면(상품 시작 또는 직접 고르기)으로 이동한다([여행 구성](../01-func/02-visitor.md#여행-구성)).

### 여행 만들기

[구성 단계](../01-func/02-visitor.md#구성-단계)와 [여행 구성](../01-func/02-visitor.md#여행-구성)을 따르며 삭제는 펼친 경고에서 확인한다.

#### 탐색·선택

- 상단에 현재 단계(전환 시 제목 포커스), 덱 위에 테마 선택·검색어와 접힌 `세부 조건`(지역·행사 날짜·동반 유형)을 둔다([구성 단계](../01-func/02-visitor.md#구성-단계)).
- 담은 카드가 없을 때만 추천 순서·`추천` 배지(뒷면 이유)를 표시하고, 담기 후에는 [이어 담기](../01-func/02-visitor.md#이어-담기) 직선거리순으로 정렬하며 앞면에 직선거리(좌표 미확인 시 안내)를 표시한다.
- 가로 스냅·스와이프·드래그·버튼·방향키로 이동하며 중앙 거리에 따른 회전·깊이 효과를 적용한다(모션 감소 시 해제). 상세 버튼으로 뒷면을 열고 카드 이동 시 앞면으로 복귀한다.
- 카드 클릭 시 선택 상태(우측 상단 체크·초록 테두리)를 갱신하고, 사진 원이 지도(좁은 화면 하단 시트·넓은 화면 옆 패널)로 이동한 뒤 덱을 거리순으로 재정렬하며 `○○에서 가까운 순으로 다시 놓았어요`를 알린다(모션 감소 시 페이드만 적용).
- 가족 체험 조건과 방문 전 확인 안내는 카드 뒷면·상세·QR 안내에서 공통 조각을 재사용한다.

#### 카드 정보·사진

- 앞면 상단에 아이콘·종류, 하단 흰 패널에 `이름 → 위치·날짜 → 상세 버튼`, 뒷면 스크롤 영역에 검토 상태·출처·확인일·사진 조건을 둔다([카드 방향](#카드-방향)).
- 관광지 사진은 약한 틴트를 적용하고, 행사·음식점/카페 사진은 배지와 패널 사이 독립 영역에 둔다([행사](../data-collection/events-data.md#이미지)·[음식점 이미지](../data-collection/dining-data.md#이미지)). 미확보 사진은 옅은 초록 바탕과 종류 선형 그림으로 표시한다.

#### 선택 목록·저장

- 덱 구성 중 넓은 화면(960px 이상)은 하단 메뉴를 유지하며 덱 오른쪽 고정 패널에 지도·담은 목록·`여행 확인`을 묶고, 좁은 화면은 하단 메뉴를 숨긴 채 하단 시트(접힘: 112px 지도 띠·선택 수·`여행 확인` / 펼침: 지도·여정 타임라인 목록)를 제공한다.
- 지도는 담은 카드 핀·순서 선만 표시하며(핀 클릭 시 덱 이동, 펼친 높이 좁은 화면 240px·넓은 화면 덱 구성 패널 280px·여행 확인 320px, 핀 없으면 덱 구성은 시흥 전체·여행 확인은 숨김, 타일 실패 시 숨김) 하단에 좌표 미확인 수를 안내한다.
- 여정 타임라인은 번호 원·사진·이름·종류·직선거리와 우측 순서/삭제 아이콘을 표시한다.
- 여행 확인은 하단 메뉴를 복원하고 `담은 카드` 옆 `덱 수정` 링크, 지도·전체 순서·이름·날짜·저장 버튼을 본문에 표시한다(비스크립트 환경은 목록·저장 폼 전체 표시, [여행 구성](../01-func/02-visitor.md#여행-구성)).

### 정보와 행동의 우선순위

- 화면당 핵심 작업 1개와 주요 행동 1개만 강조(`제목 → 정보·입력 → 실행`)하고 부가 설정은 접는다.
- 공통 토큰·용어·동사형 버튼명을 일관되게 사용하며, 모든 빈 결과·오류·제한 상태에 복구 경로를 제공하고 입력을 보존한다.
- 여행 구성(`여행 만들기·담은 카드`)과 혜택 인증(`혜택 이용권 코드`) 용어를 구분한다.
- 담당자 확인·이력은 간결한 카드로 표시해 다음 코드 조회로 연결하고, 방문객 피드백 뒤로가기는 사용 이력으로 이동한다. 새 만족도는 미선택에서 시작한다.

### 여행 기록·상태 변경

- 완료된 여행 상세는 `표지 → 이렇게 다녀왔어요(날짜·지역·장소·기록·사진·혜택 요약) → 장소별 방문일·별점·메모·사진` 순서로 표시한다.
- 장소별 `기록 남기기`(`기록 수정`)를 펼치면 별점(미선택 가능, 선택 시 빈 방문일을 여행 날짜 또는 오늘로 자동 입력)·방문일(오늘까지)·메모·사진(선택 즉시 업로드, 비스크립트 시 저장 버튼)을 저장하고 같은 장소로 돌아온다.
- 진행 중 여행 상세는 방문 순서·혜택과 `여행 마치고 기록 남기기`(확인 팝오버에서 변경·환불 불가 안내)만 제공한다([저장과 상태 변경](../01-func/02-visitor.md#저장과-상태-변경)).

### 여행 포토카드

사용 완료 여행 상세에서 본인 사진·장소명·여행명·방문일을 담은 포토카드 인쇄/PDF 화면으로 연결한다(사진 없으면 기록 업로드 안내, [여행 사진](../01-func/02-visitor.md#여행-사진)).

### 투어패스 안내

- 새 여행 만들기에서 전체 상품(`/merchants`)으로 진입하며 `혜택 받는 곳 모아 보기`로 이용 가능 시설(`/merchants?tab=facilities`, 세로 카드)을 연다(구 `tab=usage`·`tab=notes`는 전체 상품으로 이동, [혜택 이용권](../01-func/02-visitor.md#혜택-이용권)).
- 전체 상품·직접 고르기는 가로형 표지(우측 대표 사진, 좌측 접힌 혜택 목록·여행 시작 버튼, 구성·출처 팝오버)를 공유한다.
- 이용 방법은 랜딩·홈에, 투어패스 유의사항([공통 정책](../01-func/01-common.md#정책))은 구매 화면·내 투어패스에, 여행 유의사항은 여행 상세에 둔다.

### 내 투어패스

`/passes`는 `진행 중인 여행 → 접힌 유의사항 → 혜택 사용 이력(피드백 연결) → 구매 내역` 순서다. QR·코드는 진행 중 여행 상세에만 노출하며(이용권 상세에서는 연결된 진행 중 여행으로 이동 링크 제공), 환불 가능 이용권은 여행 상세·이용권 상세의 `환불하기` 확인 팝오버로 취소한다.

### 여행과 투어패스

- 가맹점 카드는 앞면에 `투어패스 · 혜택명`(연결 시 사용 가능/예정/완료 덧붙임) 배지를 표시한다.
- 여행 확인은 추천 상품(상품명·혜택 수·가격)이 있으면 `확정하고 투어패스 구매`(주)·`구매 없이 여행 확정`(보조), 없으면 `여행 확정`(주)과 `임시 저장`(보조)을 둔다.
- 진행 중 여행 상세는 연결된 투어패스(남은 시간·QR·코드) 또는 [추천 상품](../01-func/02-visitor.md#혜택-이용권)(`가격 · 구매하기`) 패널과 접힌 이름·날짜 설정을 둔다.
- 구매 화면(`/passes/checkout`)은 `여행·상품·일정·혜택(본인 부담·예약 조건) → 결제 금액·시연 결제 버튼` 순서며 기간 충돌 시 결제를 막고 내 투어패스 링크를 제공한다.

### 상세·혜택

- 관광 상세는 `사진·소개 → 위치·방문 조건 → 출처` 순서, 혜택 상세는 `본인 부담·할인 → 위치·예약 조건 → 기간·이용 흐름` 순서로 배치한다([공통 정책](../01-func/01-common.md#정책)).

## 플로팅 필 탭 바

- 하단 메뉴는 불투명 캡슐(`--radius-pill`)로 띄우고 아이콘·라벨 중앙 정렬과 브랜드색 선택 배경을 사용한다(상단 선 없음, 덱 구성 중 숨김: [선택 목록·저장](#선택-목록저장)).
- 하단 고정 작업 바도 같은 필 곡률·밝은 표면·부드러운 그림자를 사용하며 본문 여백·안전 영역을 확보한다.
