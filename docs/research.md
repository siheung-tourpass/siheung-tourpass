# 디지털 투어패스 조사

## 참고 자료

사용자 제공: 강영애·이진영, 『시흥 거북섬 투어패스 도입을 위한 검토 과제』, 시흥시정연구원 SHRI Issue Paper 제15호, 2026-06-30.

- p.3·그림 1: 디지털 패스가 이용자·가맹점·운영사를 연결하고 이용권 제시·인증·이력·정산이 이어지는 구조를 설명한다.
- pp.19~20·표 14~15: 거북섬 중심에서 오이도 등으로 확대하는 공간 범위와 단계적 사업 추진, 해양레저·가족 체험 테마를 제안한다.
- pp.28~29·표 23: 범위, 가맹점 구성, 경기투어패스와 차별성, 지역 현안 연계, 운영 방식의 다섯 검토 과제를 정리한다.
- p.30: 연구진의 견해가 시흥시 정책과 다를 수 있음을 명시한다.

보고서의 제안은 확정 정책·제휴 계약·현재 상품 정보가 아니다. 이번 작업은 첨부 자료 기반 기획 전환이며 최신 가격·시설 운영·기존 상품의 판매 상태를 별도 조사하지 않았다. 실제 정보로 등록할 때 공식 자료를 재확인한다.

## 지역 범위 변경

대상을 시흥시 전체로 확장했다. 보고서 p.29·표 23에도 배곧·시흥시 전역 확대가 검토안으로 제시되지만, 이번 범위 결정은 확정 정책을 뜻하지 않는다. 거북섬 통계는 해당 지역의 사례로만 사용한다. 구현 범위는 [요구사항](../spec.md#제품-범위)을 따른다.

## 개인 여행 패스 기획 가설

여러 안내에서 찾은 장소를 개인 패스로 구성하고 같은 공간에 여행 후 기록을 남기면 준비·회고가 쉬워지는지 확인한다. 구성→추천 담기→기록→아카이브는 이번 제품 방향이며 첨부 보고서가 입증한 효과가 아니다. 혜택 이용권은 선택 기능이다. 방문객 관찰에는 여행 생성·순서 변경·기록·보관·재조회를 추가한다.

## 혜택 이용권 문제 가설

방문객은 여러 시설의 혜택·추가 비용·예약 조건을 비교하기 어렵고, 담당자는 이용권의 유효성·중복 사용 여부를 확인해야 한다는 가설을 둔다. 통합 이용권이 선택·사용을 쉽게 하는지 관찰한다. 지역 방문·소비 증가는 별도 현장 검증이 필요하다.

## 추천·피드백 검증 가설

지역·테마·동반 유형의 관계로 추천 이유를 설명하면 장소 선택과 패스 포함 여부 이해를 돕는지 확인한다. 본인의 이용 후 평가를 반영한 추천이 다음 선택에 도움이 되는지도 관찰한다. 이는 사용자 요청으로 추가한 설계 가설이며 첨부 보고서의 결론이나 검증된 효과가 아니다. 온톨로지·추천 규칙은 [추천 의미 모델](tourism-semantics.md), 완료 기준은 [C8~C10](../spec.md#검증완료-기준)을 따른다.

## 조사할 항목

관광 추천용 공식 장소·관계 자료 수집 결과는 [수집 안내](tourism-data.md)에 기록한다. 운영·가격·예약 최신 정보 조사와 지역별 수요 검증은 별도 과제다.


| 보고서 쟁점        | 프로젝트에서 확인할 질문                                                |
| -------------------- | ------------------------------------------------------------------------- |
| 사업 범위          | 시흥시 내 지역별 수요와 이동 여건을 고려할 때 어떤 혜택 조합이 적절한가 |
| 가맹점 구성        | 핵심 시설과 주변 혜택 조합이 이용 동기를 만드는가                       |
| 기존 패스와 차별성 | 경기투어패스의 실제 선택·사용 흐름과 어떤 차이가 필요한가              |
| 지역 현안          | 교통 안내·연계 혜택이 방문 불편을 줄일 수 있는가                       |
| 운영 방식          | 제휴 모집·혜택 비용·정산·갱신을 누가 담당할 수 있는가                |

## 사용자 비교 검증 계획

방문객 역할 3명 이상과 가맹점 담당자 역할 2명 이상을 모집한다. 동일한 상품 조건을 개별 안내와 투어패스 화면으로 제시하고 순서를 교차한다. 패스 선택, 포함/추가 비용 구별, 만료 판단, 제시·사용 처리, 사용 내역 확인의 성공 여부·시간·오해·실패 이유를 기록한다. 중대 오해를 수정하고 재확인한다. 이 관찰은 [완료 기준 C7](../spec.md#검증완료-기준)을 판단하는 자료이며 수요·소비 증가 검증으로 해석하지 않는다.
