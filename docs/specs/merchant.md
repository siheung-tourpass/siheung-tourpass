# 가맹점 담당자 요구사항

공통 범위·인증·정책·완료 기준은 [공통 요구사항](../../spec.md)을 따른다.

## 사용 흐름

방문객이 제시한 코드 입력 → 자기 가맹점의 혜택·잔여 확인 → 사용 확인 순서다. 확인만으로 차감하지 않으며 최종 사용 결과를 확인한다. 실행 주소·시연 계정은 [README](../../README.md#사용-방법)를 따른다.

## 기능

| ID | 구현 조건 |
| --- | --- |
| 1 | 담당자는 자기 가맹점 혜택만 조회·확인 후 사용. 확인은 5분 내 1회. 없는 코드·만료·취소·한도 초과·타 가맹점·중복 제출 거부. |

혜택 사용의 원자성·조건 보존은 [공통 기능 2·4](../../spec.md#공통-기능)을 따른다.
