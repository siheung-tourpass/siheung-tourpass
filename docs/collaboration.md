# 이슈·PR 작성 규칙 — 시흥 투어패스

[문서 안내](../README.md#관련-문서)

[이슈 템플릿](../.github/ISSUE_TEMPLATE.md)·[PR 템플릿](../.github/PULL_REQUEST_TEMPLATE.md)과 [작업 지침](../AGENTS.md)을 따른다.

## 이슈

- 제목은 `[Bug] 요약`, `[Feature] 요약`, `[Task] 요약` 중 하나로 작성한다.
- 본문에 문제·기대 결과를 적고(버그는 재현 방법·기대/실제 동작·환경 포함), 관련 요구사항 링크 후 불필요한 템플릿 항목은 지운다.

## PR

- 제목은 `type: 요약`(`feat`·`fix`·`docs`·`refactor`·`test`·`chore`)으로 작성한다.
- 단일 목적만 다루며 변경 이유·내용·검증 결과(미실행 시 사유)·문서/마이그레이션 변경을 적는다.
- 이슈는 `Closes #123` 또는 `Refs #123`으로 연결하고 화면 변경 시 스크린샷을 첨부한다.
