# 음식점·카페 데이터

[수집 자료](../backend/data/siheung-dining.json)는 시흥시 [모범음식점](https://www.siheung.go.kr/portal/foodpreference/list.do?mId=0313010300)·[식품안심업소](https://www.siheung.go.kr/portal/foodsafety/list.do?mId=0313010100) 목록에서 확인한 일부 업소다. 전체 목록이나 맛 순위가 아니다.

## 원본·공개 기준

- 업소명·주소·업태·지정번호·지정일은 공식 표의 사실이다. 카페 구분과 검색 지역은 서비스 분류다. 폴 바셋은 공식 표의 정왕동 주소를 보존하고 아울렛을 배곧 검색 지역으로 분류한다.
- `checkedOn`은 원문 확인일, `contentDate`는 원문 기준일이다. 기준일이 없는 목록은 미확인으로 표시한다. `SOURCE_CHECKED`는 공식 목록 대조이며 관광 추천 승인과 별개다.
- 공식 지정 근거가 있는 업소만 공개한다. 원문에서 제외·취소된 업소는 자료에서 제거하며 기존 여행의 이름·주소·방문 기록은 보존한다. 코드 재사용은 금지한다.
- 위생 지정은 맛 평가로 확대하지 않는다. 영업시간·메뉴 가격·예약·현재 영업 여부는 미수집이며 화면에서 미확인으로 표시한다. 여행·추천·혜택과의 관계는 [여행 구성](../spec.md#여행-구성)을 따른다.

## 이미지

[공통 이미지 기준](tourism-data.md#이미지)에 따라 업소별 원본·이용 조건을 확인한 사진만 수집 자료의 `image`에 등록한다. 공공누리 제3유형 사진은 크롭·틴트·문구 중첩 없이 전체를 비율대로 축소한다. 미확보 카드의 표시는 [디자인 기준](design.md#카드-정보사진)을 따른다.

후보 출처·확인 상태·재개 조건은 [이미지 조사](dining-images.md)에서 관리한다.

## 적용

자료는 WAR에 포함되므로 별도 DB 적재가 필요 없다. 기존 DB 갱신은 [README의 마이그레이션 절차](../README.md#시작하기)를 따른다.
