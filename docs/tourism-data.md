# 시흥 관광 데이터 수집

데이터 원본은 [siheung-tourism.json](../backend/data/siheung-tourism.json) 하나로 관리한다. 한국관광공사·경기관광공사 공식 페이지 12개에서 실제 장소 13개, 서비스 분류 지역 9개, 테마 7개, 장소 관계 어노테이션 40개를 정리했다. 시흥 전체 관광지 목록이나 지역별 수요를 대표하는 표본은 아니다.

## 수집 범위

갯골생태공원, 오이도 선사유적공원, 시흥오이도박물관, 연꽃테마파크, 관곡지, 웨이브파크, 배곧한울공원, 은계호수공원, 물왕호수, 호조벌, 소래산, 월곶포구, 거북섬. 관곡지와 연꽃테마파크, 거북섬과 웨이브파크는 별도 장소다. 거북섬의 시설 소개를 근거로 거북섬 전체에 해양 체험 관계를 전파하지 않았다.

각 장소·관계의 근거와 URL은 원본의 `sources`·`source_ids`에서 확인한다. 예를 들어 [갯골생태공원 소개](https://access.visitkorea.or.kr/opentour/detail.do?cotId=44219c7f-c556-474b-b92d-92505fa93199)는 생물 관찰, [오이도박물관 기사](https://korean.visitkorea.or.kr/detail/rem_detail.do?cotid=264ef757-a6e8-48f3-9724-904ae9a84fc3)는 유물 전시·어린이 체험·가족 방문 근거로 사용했다.

## 세 계층에 연결


| 계층          | 원본 항목                                               | 적용                                                                                                                                   |
| --------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 어노테이션    | `places`, `annotations`, `sources`                      | 장소 소개와`locatedIn`·`hasTheme`·`suitableFor` 각각에 근거·확인일·검토 상태 기록                                                  |
| 온톨로지      | `regions`, `themes`, `companion_types`, `theme_parents` | [관계 사전](tourism-semantics.md#2-온톨로지)의 타입 사용. 신규 테마 4개는 독립 개념이며 부모 관계 자동 생성 없음                       |
| 시맨틱 레이어 | `semantic_examples`와 승인된 관계                       | [기존 점수 계약](tourism-semantics.md#4-시맨틱-레이어)으로 지역 필터·상위 테마 추론·설명 생성. 기대값은 승인 가정이며 실행 결과 아님 |

외부 자료의 사실 요약은 `SOURCE_FACT`, 테마·서비스 지역 배정은 `PROJECT_CLASSIFICATION`, 서비스 개념 정의는 `PROJECT_MODEL`로 구분한다. 테마는 공식 기관의 추천 분류라고 주장하지 않는다. 가족 관계는 직접 근거를 확보한 2곳만 기록했으며 친구 관계는 근거가 없어 비웠다. 관계 없음은 정보 없음이다.

## 저장·승인 규칙

- 모든 장소·개념·관계는 `DRAFT`, `reviewed_by`·`reviewed_at`은 `null`이다. `active=true`는 저장상의 활성 후보이며 승인·영업 여부가 아니다. 현재 상태로는 추천 결과 0건이다.
- `source_ids`는 같은 파일의 `sources.code` 외래 참조다. DB 적재 시 URL·확인일은 해당 출처에서 해석하여 `place_source`와 관계별 검토 메타데이터에 연결한다. 이 파일은 적재용 자료이며 DB 초기화 코드가 아니다.
- 장소의 `region_code`와 `locatedIn`은 같아야 한다. 각 장소에 지역은 정확히 1개다. 코드는 표시명 변경 후에도 유지하며 `PLACE_A` 등 기존 시연 ID와 혼합하지 않는다.
- 지역은 관광 검색용 분류이며 행정구역 경계가 아니다. `전체`는 저장하지 않는다. 주소는 출처에서 별도로 확인된 수준만 기록하고, 근거가 없으면 `null`이다.
- 원본 확인일 `checked_on`과 기사 작성·갱신일 `content_date`를 구분한다. 오래된 기사도 장소의 역사·특성에 한해 수집했으며 최신 운영 확인으로 취급하지 않는다.
- 실제 관광 자료는 `REAL`, 서비스의 테마 부모 설정은 `DEMO`·`PROJECT_MODEL`이다. 실제 가맹점·혜택 연결은 모두 빈 배열이다. 승인된 장소는 개인 여행 패스에 담을 수 있다. 직접 남긴 방문 날짜·메모·만족도는 개인 아카이브용이며, 추천의 개인 보정은 기존 성공한 시연 혜택 피드백 규칙만 따른다.

## 미확인·추가 수집

현재 운영·가격·예약·운영시간·좌표는 `null`·`UNKNOWN`이다. 화면에는 `미확인`으로 표시한다. 열린관광 페이지의 접근성 정보는 특정 시설·구간에 대한 자료이므로 전체 장소의 안전성·무장애 적합성으로 추론하지 않았다. 원문·이미지·음성을 복제하지 않고 사실을 짧게 재서술했다.

관리자 검토 때 장소 소개와 관계를 각각 승인해야 한다. 갯골 가족 관계는 2020년, 박물관 가족·체험 관계는 2022년 기사 근거이므로 최신 기관 안내를 우선 재확인한다. 배곧 기사에는 공원과 해수풀 휴무 표현이 섞여 있어 운영 조건을 수집하지 않았다. 월곶 한국어 상세 페이지는 열기 오류로 영문 공식 페이지의 포구·위치만 사용했다.

벅스리움·시흥에코센터·해양생태과학관 등은 이번 원본에 넣지 않았다. 기관 본문·위치·관계 근거를 확인한 뒤 같은 형식으로 확장한다. 관리자 승인, DB 적재, 실제 앱 추천 검증은 후속 작업이다.
