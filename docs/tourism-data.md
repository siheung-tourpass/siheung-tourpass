# 관광 데이터

## 원본

[siheung-tourism.json](../backend/data/siheung-tourism.json)의 `sources`·`source_ids`에 출처·근거를 둔다. 장소 목록·건수·추천 예시는 JSON만 갱신한다.

행사 카드 준비용 수집 자료와 이미지 검토는 [행사 데이터](events-data.md)를 따른다.

- 사실 요약 `SOURCE_FACT`, 서비스 분류 `PROJECT_CLASSIFICATION`, 자체 개념 `PROJECT_MODEL`을 구분한다. 실제 자료는 `REAL`, 자체 테마 부모는 `DEMO`·`PROJECT_MODEL`; 실제 가맹점·혜택 연결은 없다.
- 지역은 행정구역이 아닌 검색 분류. 장소당 지역 1개, `region_code`와 `locatedIn` 일치, `전체` 미저장. 표시명 변경 시 코드 유지·시연 ID와 분리.
- `source_ids`는 같은 파일의 `sources.code` 참조이며 적재 시 출처 메타데이터로 해석한다. `checked_on`과 원문 `content_date`를 구분한다.
- 주소·운영·가격·예약·좌표 등 근거 없는 값은 `null`·`UNKNOWN`. 특정 시설·구간 근거를 전체 장소·시흥시의 특성으로 확대하지 않는다. 관광 소개 출처의 원문·이미지·음성은 복제하지 않으며 사진은 별도 [이미지 기준](#이미지)을 따른다.

## 적재

기본 적재는 [README](../README.md#시작하기)를 따른다. 기존 시연 DB에 실제 자료를 아직 적재하지 않았다면 백업 후 저장소 루트에서 아래 명령을 1회 실행한다. 이미 적재한 DB에는 재실행하지 않고 관리자 화면에서 근거·확인일을 갱신한다.

```sh
python3 backend/scripts/tourism-sql.py --replace-demo > /tmp/siheung-tourism.sql
psql -X -v ON_ERROR_STOP=1 -U postgres -d siheung_tourpass < /tmp/siheung-tourism.sql
```

모든 장소·개념·관계는 `DRAFT`, 검토자·시각은 `null`로 적재한다. `active=true`는 승인·영업을 뜻하지 않는다. 관리자가 장소와 관계를 각각 승인하기 전에는 추천에서 제외한다. 의미 자료를 수정하면 다시 검토한다.

이미 실제 자료가 있는 DB에 새 장소만 추가하려면 위 생성 명령에 `--place-code 장소코드`를 필요한 만큼 반복한다. 코드는 JSON에서 확인하며 아직 적재하지 않은 장소만 지정한다. 기존 장소의 승인·수정 내용은 덮어쓰지 않으며, 중복 적재는 트랜잭션 전체가 실패한다.

`--replace-demo`는 가상 장소와 시연 빈 지역을 비활성화하며 기존 여행·발급·사용 기록을 삭제하지 않는다. 테스트에서는 옵션 없이 가상 후보를 유지한다. 출처에 기록된 주소는 위치 설명으로 적재하며 상세 주소가 없는 장소는 `상세 주소 미확인`을 표시한다.

## 검토

- 소개·위치 근거는 JSON의 확인일에 원문을 재확인했다. 갯골 가족 관계(2020년), 박물관 가족·체험 관계(2022년)는 당시 소개의 근거이며 현재 프로그램 조건은 미확인이다.
- 경기둘레길 안내에 과거 공사·우회 문구와 호조벌의 복수 주소가 함께 남아 있다. 호조벌 주소는 추천 장소 단락의 위치이며 전체 경계·진입점이 아니다. 현재 경로·접근성은 미확인이다.
- 배곧 공원/해수풀의 운영 표현이 혼재하여 운영 조건은 미수집. 월곶은 공식 영문 페이지의 포구·위치만 사용했다.
- 옥구공원 주소는 최신 확인 페이지를 사용했다. 시흥에코센터의 과거 프로그램 일정은 현재 조건으로 사용하지 않는다. 오이도 단지 내 시설은 개별 주소 미확인으로 두며, 조수·개방·통행 조건과 프로그램 참여 가능성은 별도 확인이 필요하다.
- 추가 장소는 공식 소개·위치·관계 근거를 확보한 뒤 같은 형식으로 등록한다. 수집 자료는 시흥 전체 관광지·수요의 대표 표본이 아니다.

## 이미지

[이미지 메타데이터](../backend/src/main/resources/place-images.json)에 장소 코드·대체 텍스트·촬영자·원본 출처·라이선스·확인일을 둔다. Wikimedia Commons의 개별 라이선스 사진과 공공기관이 공공누리 제1유형으로 개방한 사진을 [정적 자산](../frontend/assets/places)에 함께 배포한다. 사용자 요청마다 외부 이미지를 호출하지 않는다.

공식 사진은 게시물의 이용 조건이 사진에도 적용되는지 확인하고, 제3자 사진 제외·텍스트 한정 허용 자료는 사용하지 않는다. 저작물명·제공 사이트·공개 이미지 URL·검토 근거를 메타데이터에 보존한다. 촬영연도는 확인된 경우만 기록하며 게시일과 구분해 표시한다. 공공누리는 로그인 없이 공개된 미리보기 사진을 사용하고 별도 신청이 필요한 고해상도 원본은 수집하지 않는다.

사진을 추가할 때 실제 장소·촬영 대상을 대조하고 원본 설명 페이지의 이용 조건을 확인한다. 일반 상세는 사진 전체를 비율대로 축소하며, 여행 카드 배경은 세로 비율에 맞춰 크롭·틴트를 적용한다. 원본 파일은 보존하고 촬영자·출처·라이선스 및 화면 편집 여부를 표시한다. 사진은 현재 운영 상태의 증거가 아니며, 미확보 장소에 다른 장소 사진이나 생성 이미지를 대신 쓰지 않는다. 사진 등록은 장소·관계의 추천 승인을 대체하지 않는다.
