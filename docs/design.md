# 디자인 기준

## 공통 규칙

- 기존 초록·밝은 바탕과 로컬 한국어 고딕을 사용한다. 값은 [토큰](../frontend/assets/tokens.css), 스타일은 [style.css](../frontend/assets/style.css)가 원본이다.
- 모바일 한 열, 명확한 제목·짧은 안내·충분한 여백. 주요 행동은 초록, 보조 행동은 회색, 삭제·취소는 적색이다.
- 주요 입력·버튼 52px 이상, 보조 조작 영역 44px 이상, 상시 라벨·실제 체크박스·키보드 포커스. 자동 애니메이션은 쓰지 않는다.

## 공통 시각 체계

- 두 서비스는 중립 회색 바탕·흰 표면·시스템 한국어 글꼴, 최대 1040px 콘텐츠 폭을 공유한다. 고유 강조색은 유지한다.
- 제목은 28~40px, 섹션 제목은 20px. 본문 16px·행간 1.65, 보조 설명 14px로 위계를 구분한다.
- 바깥 여백은 24px(작은 화면 20px), 패널 안쪽은 32px(작은 화면 20px). 컨트롤 곡률 14px·패널 24px, 입력·주요 버튼 높이는 52px다.
- 화면마다 주요 행동을 강조색 채움으로 표시하고 보조 행동은 중립 표면으로 구분한다. 현재 메뉴·선택 항목은 배경과 굵기, 체크 표시를 함께 쓴다.
- 입력 경계와 키보드 포커스는 3:1, 본문은 4.5:1 이상 대비를 유지한다. 하단 메뉴는 아이콘·짧은 라벨을 한 줄로 배치한다.
- 자동 등장 효과 없이 짧은 누름 반응만 사용하고 모션 감소 설정을 존중한다. 320·375·414·768px에서 가로 넘침과 조작 영역을 확인한다.

## 화면 구성

- 공통: 상단 브랜드 → 제목·설명 → 입력·결과, 역할별 주요 메뉴는 하단 고정 내비게이션에 둔다. 본문·포커스가 메뉴에 가리지 않도록 여백과 기기 안전 영역을 확보한다. 방문객 하단 메뉴는 홈·여행 만들기·내 패스·여행 기록·프로필 5개이며 모두 아이콘을 표시한다. 제작 중·확정·완료를 각 메뉴로 분리한다. 상단은 브랜드만 표시하며 계정·화면 설정·로그아웃은 프로필에 둔다. 정상·빈 결과·실패 상태에서 다음 행동을 안내한다.
- 홈은 여행 카드 탐색, 방문객은 여행 구성·기록을 우선한다. 관광 추천·가맹점/혜택 독립 메뉴는 두지 않는다. 여행 패스와 시연 혜택 이용권을 구분하고 시연 표시·추천 근거를 유지한다.
- 제작 중·내 패스·여행 기록의 목록은 상태·여행 이름·날짜와 선택 카드 수를 구분한 패스 형태를 공유한다. 넓은 화면은 절취선 옆에 카드 수·열기 버튼을 두고, 모바일은 하단으로 배치한다. 절취선 장식은 패스 안으로 파인 형태이며 제작 중 패스 삭제는 우측 상단에 둔다. 제작 중 목록 위에서 템플릿 시작과 빈 여행 시작을 제공한다.
- 여행 만들기는 관광지·행사·가맹점 통합 카드 보드 → 카드 선택 목록·순서 확인 → 이름·선택 날짜 임시 저장 또는 제작 확정 순서다. 제작 중은 같은 카드 보드에서 이어 만들며 삭제는 펼친 경고 안에서 실행한다. 여행 기록 입력은 좌우 스크롤·스와이프·이전/다음 버튼·방향키로 카드를 탐색하며, 이동 중 입력을 유지하고 저장 후 같은 카드로 복귀한다. JavaScript가 없으면 기록 폼을 목록으로 제공한다. 확정 패스는 사용 완료 버튼으로 아카이브하며 복원 시 확정 목록으로 이동한다. 검색·종류·행사 날짜로 카드를 찾고, 지역은 관광지·가맹점에만 적용한다. 취향 찾기는 최대 3개 관광지 카드와 근거를 보드 안에서 강조한다. 카드 섞기는 표시 순서만 바꾸고 선택 목록은 유지한다. 상세는 카드를 뒤집어 확인하며 선택·누름 반응과 모션 감소를 지원한다. 관광지·행사·가맹점 모두 같은 선택·상세·저장 조작을 제공한다. 이미지가 없는 행사 카드는 가맹점과 같은 단색 배경을 사용하고 이미지 준비 문구는 표시하지 않는다. 카드는 세로 3:2 비율의 사진 배경 위에 어두운 틴트·밝은 정보를 배치한다. 가로 스크롤 스냅·터치 스와이프·마우스 드래그로 탐색하며 중앙 카드와 양옆 카드의 크기·강조를 구분한다. 선택·저장은 내 여행 덱 대화상자에 모아 카드 수에 따른 페이지 길이 증가를 막는다. 하단 덱 버튼에는 제작 확정 진입을 표시하고 덱 창의 저장·확정 버튼은 스크롤 영역 밖에 고정한다. 하단 덱 열기 버튼은 메뉴 위에 두고 본문·포커스를 가리지 않는다. 카드 앞면 상단에는 종류만 표시하고 하단에 이름·위치·상세 버튼을 둔다. 상세 버튼으로 카드를 뒤집어 뒷면의 스크롤 영역에서 상세·검토 상태·사진 이용 조건을 확인한다. 다른 카드로 이동하면 앞면으로 복귀한다. 카드 클릭으로 선택·해제하며 초록색 테두리와 접근성 선택 상태를 함께 갱신한다. 선택 후 자동으로 다음 카드로 넘기지 않는다. 앞·뒷면 전환 버튼은 우측 하단에 두고 설명과의 간격을 좁힌다. 선택 테두리는 밝은 안쪽 선을 함께 사용해 사진과 구분한다. 좌우 이동 중에는 중앙에서의 거리에 따라 회전·깊이를 바꾸며 모션 감소 설정에서는 끈다. 이전·다음 버튼과 방향키도 제공한다. 검토 대기 관광지의 담기 정책은 [요구사항](../spec.md)을 따른다. JavaScript가 없으면 카드 목록과 저장 폼을 모두 표시한다. 빈 목록은 조건 변경을 안내한다.
- 관리 화면은 같은 셸 안에 메뉴·목록·편집 폼을 배치한다.
