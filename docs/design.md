# 디자인 — siheung-tourpass

## 방향

간결한 정보 위계와 여유 있는 간격을 적용한 modern-minimal 앱. 브랜드 초록을 유지하며 관광 추천 → 여행 구성 → 기록으로 안내한다.

## 공통 구조

- 홈: 왼쪽 정렬 소개와 주요 행동, 이어지는 여행 안내 목록.
- 앱: 상단 브랜드·역할별 메뉴, 페이지 제목·설명, 입력 패널과 결과 목록.
- 관리: 같은 셸 안에서 메뉴·목록·편집 폼을 순서대로 제공한다.

## 시각 기준

- 색상·글꼴·간격·모서리의 원본은 [tokens.css](../frontend/assets/tokens.css). 루트 [tokens.css](../tokens.css)는 이 파일을 가져온다.
- 브랜드 #175940, 링크 #12604b. 밝은 회색 배경, 흰 표면, 진한 제목과 보조 설명.
- Apple SD Gothic Neo·Noto Sans KR·맑은 고딕 순의 로컬 한글 글꼴. 제목 700, 본문 400, 버튼 600.
- 4px 기반 간격, 12px 입력·버튼, 24px 패널. 모바일에서 단일 열.
- 주요 버튼은 초록, 보조 행동은 회색, 삭제·취소는 적색. 화면마다 다음 행동을 명확히 한다.
- 최소 44px 조작 영역, 즉시 표시되는 포커스, 실제 체크박스와 label 사용.
- 자동 애니메이션 없음. 결과는 서버 응답으로 확인하며 필수 시연 표시·추천 근거를 유지한다.

## 화면별 적용

홈·로그인(page.jsp), 추천(recommendations.jspf), 여행(journeys.jspf), 탐색(catalog.jspf), 이용권(passes.jspf), 사용·피드백(usage.jspf), 관리(admin.jspf)가 공통 스타일을 사용한다.
