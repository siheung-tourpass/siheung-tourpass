## 관리자 작업과 카드 출력

### 자료 관리

- 관광지는 편집·검토하고 행사·음식점·카페는 공개 안내만 확인한다. 가상 가맹점은 실제 관광지 또는 공식 지정 음식점·카페 카드 1개에 연결한다([관리자 화면 기준](../02-uxui/01-design.md#관리자)).

### 카드 출력

- 공개 관광지·행사·음식점/카페를 선택해 사진(없으면 문자형)과 공개 안내 QR을 담은 `90×130mm` 포토카드(문구 40자, 1~4장, A4 인쇄/PDF 미리보기, 설정 미저장)를 제작한다.
- QR은 지정한 기본 URL의 비로그인 안내 페이지로 연결한다(개인정보·코드 미포함, 비공개 전환 대상 조회 거부, [사용 방법](../../README.md#사용-방법) 참고).
- 사진 이용 기준은 [관광](../data-collection/tourism-data.md#이미지)·[행사](../data-collection/events-data.md#이미지)·[음식점](../data-collection/dining-data.md#이미지)을 따르며 비영리 안내용으로만 출력한다.
