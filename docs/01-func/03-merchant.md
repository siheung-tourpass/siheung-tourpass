## 사용 흐름

코드 입력 → 배정 가맹점 혜택·잔여 확인(미차감) → 사용 확인 → 결과·이력 확인 순서다([사용 방법](../../README.md#사용-방법)).

## 기능

| ID | 구현 조건 |
| --- | --- |
| 1 | 배정 가맹점 혜택만 조회·확인(5분 내 1회 유효) 후 사용 처리한다. 없는 코드·만료·취소·한도 초과·타 가맹점·중복 제출을 거부한다([공통 기능 2·4](01-common.md#공통-기능)). |
