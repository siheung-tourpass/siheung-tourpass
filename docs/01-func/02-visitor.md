# 방문객 요구사항 — 시흥 투어패스

[문서 안내](../../README.md#관련-문서) · [공통 요구사항](01-common.md)

## 공개 탐색

관광지·행사·시흥시 공식 지정 음식점/카페를 여행 만들기 카드 탐색으로 통합한다. 비로그인 탐색을 허용하며 저장은 방문객 로그인 후 제공한다([역할별 메뉴](../02-uxui/01-design.md#역할별-메뉴)).

## 기능

### 혜택 이용권

| ID | 구현 조건 |
| --- | --- |
| 1 | 비로그인 목록·상세에 가맹점·지역/위치·혜택·기간·비용·예약 조건을 표시하고 상품 가격은 여행 구성 후 구매 안내에 표시한다(시연 경고 미표시, 미확인 정보는 `미확인` 표시). |
| 2 | 본인에게만 시연 결제로 발급하며 고유 코드(URL·로그 노출 금지)·가격·시작/만료를 표시한다. 기간 중복 이용권은 거절하고 여행에서 구매 시 자동 연결한다([정책](01-common.md#정책)). |
| 3 | 본인의 활성/만료/취소 이용권·잔여·사용 이력을 조회한다. 미사용·미만료·여행 미완료 본인 이용권만 확인 후 환불한다. |

- 가맹점 연결 카드는 혜택을 표시한다. 여행 확인 및 미연결 확정 여행에는 담은 카드의 혜택 수가 가장 많은 상품(동률 시 최저가)을 추천하며, 여행 확인에서는 확정과 구매 이동을 한 번에 처리한다.
- 상품 목록·상세는 포함 혜택과 여행 시작만 제공한다(가격·구매 버튼 없음, 비로그인은 로그인 안내). 내 투어패스는 진행 중 여행·사용 이력·구매 내역을 제공하며 코드·남은 시간·잔여는 진행 중 여행 상세나 이용권 상세에서 확인한다([투어패스 안내](../02-uxui/01-design.md#투어패스-안내) · [내 투어패스](../02-uxui/01-design.md#내-투어패스)).

### 추천·피드백

| ID | 구현 조건 |
| --- | --- |
| 4 | 비로그인도 지역(전체 가능, 필터)·복수 테마·동반 유형 1개(순위 기준, 미선택 허용)로 최대 3곳과 근거를 조회한다. 빈 결과 시 지역을 임의 완화하지 않고 조건 변경을 안내한다([추천 모델](../03-tech/02-tourism-semantics.md)). |
| 5 | 본인 성공 혜택 사용당 평가 1건(만족도 1~5, 사유: 흥미/동반 적합/비용/안내 복수 선택, 의견 500자)을 작성·수정·삭제한다(만료·취소 후 가능, 실패/타인 거부, 원문 본인만 공개). |
| 6 | 본인의 현재 피드백만 다음 추천에 즉시 반영·보존한다. 평가 장소에는 항상 적용하고, 흥미 또는 사유 미선택 시 보존 테마가 겹치는 장소에도 적용한다(동반/비용/안내만 선택 시 해당 장소만 적용, 장소·테마 중복 시 1회만 반영). |

### 여행·행사

| ID | 구현 조건 |
| --- | --- |
| 7 | 관광지·행사·음식점/카페로 개인 여행을 구성·임시 저장·확정한다([여행 구성](#여행-구성)). |
| 8 | 장소별 방문일(미래 불가)·메모 500자·만족도 1~5(방문 표시 후)를 저장·수정·비운다. 확정 여행을 사용 완료 처리하면 아카이브하며(되돌리기·이름/날짜 수정 불가), 기록·사진 수정과 포토카드 조회는 본인 아카이브에서만 허용한다([여행 기록·상태 변경](../02-uxui/01-design.md#여행-기록상태-변경)). |
| 9 | 비로그인 둘러보기·여행 만들기에 행사 카드(일정·장소·비용·예약·출처·확인일·검토 상태, KST 기준 예정/기간 중/종료 구분, 종료일 포함 날짜 검색)를 표시한다. 검토 대기 행사는 안내만 공개하며(추천·예약 가능 미표시), 사진은 [행사 데이터](../data-collection/events-data.md)를 따른다. |

## 여행 구성

기능 7의 세부 조건이며 화면 조작은 [여행 만들기](../02-uxui/01-design.md#여행-만들기)를 따른다.

### 시작과 탐색

- 전체 상품에서 투어패스로 시작(포함 혜택 장소를 순서대로 중복 없이 담음; 혜택 없음·담기 불가 장소 포함 시 차단 및 사유 표시)하거나 직접 카드를 골라 시작한다. 상품 선택만으로 저장·구매되지 않으며 저장 전 수정할 수 있다.
- 같은 보드에서 검색어·종류·지역(관광지·음식점/카페 한정)·행사 날짜로 탐색하며 조건 변경 시에도 선택을 유지한다.

#### 구성 단계

- `덱 구성 → 여행 확인` 화면으로 구분하며 모든 편집은 덱 구성부터 연다.
- 담은 카드가 없으면 테마·지역·동반 유형 기반 추천 관광지와 근거를 앞에 두고, 담기 시작하면 [이어 담기](#이어-담기) 순서를 따른다. 이전 단계 복귀나 전체 해제 시에도 단계·입력값을 유지한다.

#### 이어 담기

- 마지막 선택 카드의 대표 좌표 기준 직선거리순으로 미선택 후보를 정렬한다(실제 이동거리·경로 미추정, 좌표 미확인 후보는 후순위, 기준 좌표 미확인 시 동일 지역 우선). 행사 지역은 연결된 공개 관광지 기준이며 미연결 시 미확인으로 둔다.
- 지도에는 담은 카드만 순서 번호와 직선으로 잇고 앞 카드와의 직선거리·좌표 미확인 카드 수를 안내한다.

#### 안내 자료

- 음식점/카페는 시흥시 공식 지정 근거·확인일·기준일을 표시하며 가상 가맹점 연결 카드에만 혜택을 표시한다([음식점 데이터](../data-collection/dining-data.md)).
- 관광지 선택 후 행사·음식점/카페 비교와 가족 동반 조건 확인을 안내하며, 실제 관광지 상세에 [방문 조건 검토 항목](../data-collection/tourism-data.md#방문-조건) 안내를 표시한다.

### 저장과 상태 변경

- 선택 카드·순서와 이름(100자)·선택 날짜를 원자적으로 저장한다(빈 임시 저장 허용, 확정 시 카드 1개 이상 필수).
- 제작 중 여행은 복원해 수정·임시 저장·확정·삭제한다. 확정 여행은 구성 변경·삭제를 차단하며, 미연결 확정 여행(또는 환불로 연결 해제된 여행)만 제작 중으로 되돌릴 수 있다. 투어패스 연결 여행과 사용 완료 여행은 되돌리기·삭제를 차단한다.

### 담기와 보존

- 활성 지역의 승인 장소·검토 대기 실제 활성 관광지·공개 행사·공식 지정 음식점/카페를 중복 없이 담고 순서 이동·삭제를 제공한다.
- 담을 때 종류·고유 키·이름·지역·위치·실제/시연 구분을 스냅샷으로 보존해 이후 비활성화·검토 변경 시에도 본인 조회를 유지한다.

## 여행 사진

- 본인 여행 기록 카드마다 직접 촬영한 JPEG·PNG 1장(8MB 이하, 최대 1,600만 화소, 이미지 검증·메타데이터 제거)을 업로드·교체·삭제하며 본인만 조회한다(카드 삭제 시 함께 삭제).
- 사용 완료 여행의 포토카드는 [카드 출력](04-admin.md#카드-출력) 규격으로 본인 사진이 있는 카드만 출력한다(개인정보 QR 미생성).
