# 디자인 기준 — 시흥 투어패스

[문서 안내](../../README.md#관련-문서)

화면 배치·조작·시각 자산을 관리한다. 기능·권한은 [요구사항](../func-specs/01-common.md), 구현 경계는 [구현 계획](01-plan.md)을 따른다.

## 공통 규칙

색·크기·곡률·여백·글꼴의 값은 [토큰](../../frontend/assets/css/tokens.css), 적용 방식은 [스타일](../../frontend/assets/css/style.css)을 원본으로 관리한다. 이 문서는 화면 구성과 상호작용 기준을 설명한다.

- 초록 강조색·중립 회색 바탕·시스템 한국어 글꼴을 사용한다. 모바일은 한 열을 기본으로 하고 제목·설명·주요 행동의 위계를 분명히 한다.
- 둥근 연속 곡면과 밝은 가장자리를 불투명 표면으로 표현하고, 뉴모피즘의 부드러운 입체감은 낮은 농도의 짧은 그림자로만 표현한다. 카드·메뉴·팝오버는 같은 표면과 그림자 체계를 공유하며 두꺼운 외곽 그림자는 사용하지 않는다. 배경 블러는 쓰지 않으며 그림자·사진 틴트·대화상자 바깥 배경에만 투명도를 허용한다.
- 입력은 불투명한 옅은 중립 표면과 명확한 경계를 사용한다. 주요 행동은 강조색 채움, 보조 행동은 흰 표면, 위험 행동은 오류색과 문구로 구분한다. 선택·오류는 색만으로 전달하지 않는다.
- 입력·주요 버튼 높이는 52px 이상이다. 상시 라벨·키보드 포커스를 제공하고 본문 대비 4.5:1, 입력 경계·포커스 대비 3:1 이상을 유지한다. 입력 오류는 input·select·textarea에 같은 기준으로 표시한다.
- 자동 등장 효과는 쓰지 않으며, [홈 배경](#홈)의 연속 이동만 예외로 허용한다. 짧은 누름 반응을 사용하며 모션 감소 설정에서는 이동 효과를 끈다.

## 공통 화면 틀

- 고정 상단의 프로젝트명을 중앙에 두고 좌우에 같은 조작 영역을 확보한다. 왼쪽은 상세·하위 화면의 돌아가기 버튼에만 사용한다. 본문·앵커·키보드 포커스가 상단에 가리지 않게 한다.
- 하단 내비게이션과 고정 작업 버튼은 [플로팅 필 탭 바](#플로팅-필-탭-바)의 표면·선택·안전 영역 기준을 따른다.
- 보조 조작 영역은 44px 이상으로 제공하고 선택 입력에는 실제 체크박스를 사용한다.
- 팝업은 화면 가로·세로 중앙에 표시한다. 최대 폭 640px·좌우 여백 16px, 내비게이션과 같은 곡률·표면·그림자와 공통 배경 음영을 사용한다. 제목과 닫기를 상단에 두고 긴 내용은 내부에서 스크롤한다. 닫기·Esc와 실행 버튼으로의 포커스 복귀를 유지한다.

## 카드 방향

- 여행 패스·혜택 이용권·상품은 명함 느낌의 가로형 카드다. 절취선·파인 모서리·분리된 우측 구획은 사용하지 않는다. 정보는 왼쪽, 상태·수량·주요 동작은 오른쪽에 두되, 좁은 화면의 상품·혜택 이용권은 동작을 정보 아래에 배치한다. 긴 설명이 펼쳐지면 높이를 늘려 내용을 보존한다.
- 관광지·행사·가맹점·혜택 조건은 세로형 카드다. 사진 또는 제목 아래에 정보를 배치하며 기본 가로:세로 비율은 2:3이다. 상세·폼·출처가 길면 높이를 늘리고 탐색 덱만 고정 비율과 내부 스크롤을 사용한다.
- 대상에 따라 방향을 결정한다. 패스 상세에서도 개별 장소·혜택 카드는 세로형을 유지한다. 카드 너비·비율은 [토큰](../../frontend/assets/css/tokens.css)을 공유한다.

## 화면 구성

상단 브랜드 → 제목·설명 → 입력·결과 순서로 구성한다. 공통 헤더는 시흥시 BI와 프로젝트명을 함께 표시하고 랜딩·관리자 외 홈·로그인에는 시흥시 캐릭터를 배치한다. 파비콘·모바일 홈 화면 아이콘은 기존 투어패스 아이콘을 사용한다. 정상·빈 결과·실패 상태에서 다음 행동을 안내한다. 여행 상태는 [저장과 상태 변경](../func-specs/02-visitor.md#저장과-상태-변경)을 따른다. 관리 화면도 같은 화면 틀 안에 메뉴·목록·편집 폼을 배치한다.

### 역할별 메뉴

| 역할 | 주 메뉴·구성 |
| --- | --- |
| 방문객 | 하단: 홈 → 여행 만들기 → [내 투어패스](#내-투어패스) → [내 여행](#패스-목록표지) → 프로필. 상단: 헤더 아래 [투어패스 안내](#투어패스-안내) 탭. 설정·로그아웃은 프로필에만 둔다. |
| 관리자 | 홈 → 관광 관리 → 혜택 관리 → 통계 → 프로필. 관광 관리는 현황·관광지·개념·관계 검토, 혜택 관리는 상품·가맹점·혜택·이용권을 묶고 현재 화면의 세부 메뉴만 표시한다. |

랜딩·로그인의 메뉴 노출과 역할별 로그인 이동은 [공통 인증](../func-specs/01-common.md#공통-화면과-인증)을 따른다.

### 관리자

홈은 자료 수·검토 대기 → 관광 관리·혜택 관리·통계 바로가기 → 공개 화면 확인 순서로 배치한다. 방문객용 여행 만들기·이용 안내는 표시하지 않는다. 관광 관리의 카드 선택 목록은 방문객 탐색 카드의 2:3 앞면·종류 배지·하단 정보 패널을 공유하며 사진·종류·이름·위치를 표시한다. 이름·위치 검색과 관광지/행사/음식점/카페 필터를 제공하고 결과를 나누어 표시한다. 사진은 원본 비율을 유지하며 출처는 연결된 상세 안내에서 확인한다. 대상별 변경 권한은 [관리자 요구사항](../func-specs/04-admin.md#자료-관리)을 따른다.

- 관광 관리: 지역·테마·관계는 접힌 보조 메뉴에 둔다.
- 혜택 관리: 상품 카드에 연결 가맹점·혜택을 표시한다. 편집 폼은 기존 카드 또는 새 자료 등록을 선택한 뒤 표시한다. 장소·가맹점은 세로형, 상품은 가로형이다.
- 카드 출력: 관광 관리 카드 → 상세의 정보·출처 확인 → 카드 출력 → 문구·수량 설정 → 미리보기·인쇄. 상세 상단에서 편집·출력을 선택하며 출력 설정에서 선택한 카드의 사진·이름·종류를 표시한다. 출력 설정에서는 카드 목록을 반복하지 않고 관광 관리로 돌아가 다른 카드를 선택한다. QR 주소·인쇄 기준은 접힌 설정에 둔다.
- 편집은 넓은 화면에서 목록·폼 두 열, 모바일 한 열이다. 목록은 이름·코드 검색과 활성 상태·장소 검토 상태 필터를 제공한다. 선택 상태·저장 결과·필수 입력을 표시하고 저장·검토·비활성화를 구분한다. 비활성화는 영향 안내를 펼친 뒤 실행한다.
- 인쇄 시 탐색·메뉴·폼을 숨기고 [포토카드 규격](../func-specs/04-admin.md#관리자-작업과-카드-출력)에 맞춰 배치한다. 사진 원본 비율과 QR 흰 여백을 보존한다.

### 관광지 피드백

관광지 상세 아래에 만족도 선택·선택 의견·저장·기존 평가 삭제를 배치한다. 비로그인은 로그인 링크를 제공하고 저장·삭제 후 결과를 안내한다. 독립 통계 메뉴의 피드백 통계는 관광지별 응답 수·평균과 점수별 건수를 카드로 표시해 모바일에서도 읽을 수 있게 한다.

### 랜딩·로그인

랜딩은 [홈 배경](#홈)·서비스 소개·로그인·공개 카드 탐색 순서로 안내한다. 로그인은 아이디·비밀번호와 오류 안내·둘러보기 링크를 제공하며 계정 역할을 사용자가 선택하지 않는다. 계정 로그인 아래에 노란색 말풍선 아이콘의 ‘카카오톡으로 로그인’ 버튼을 둔다. 카카오 인증 설정이 없으면 비활성화한다. 설정 후에는 카카오 동의 화면으로 이동하며 취소·실패·만료 시 로그인 화면에서 다시 시도하도록 안내한다. 두 화면은 공통 브랜드와 스타일을 사용한다. 메뉴 노출·로그인 이동은 [공통 인증](../func-specs/01-common.md#공통-화면과-인증)을 따른다.

### 홈

랜딩·관리자 외 역할의 홈 상단에 공개 탐색의 관광지·행사 카드를 요청마다 무작위로 고른다. 넓은 배경 영역에 2:3 비율로 배치하고 제목·주요 행동을 아래에 둔다. 카드 묶음을 복제해 오른쪽에서 왼쪽으로 끊김 없이 이동하며, 일시정지 조작과 모션 감소 설정에서는 멈춘다. 관광지 사진은 카드에 맞춰 크롭하고 행사 이미지는 원본 비율로 전체 표시하며 문구를 겹치지 않는다. 사진 출처 버튼으로 공통 중앙 팝업을 열어 카드별 [공통 이미지 표기 항목](../data-collection/common.md#이미지)을 제공한다. 배경 이미지는 지연 로딩하지 않으며 반복 사본은 보조기술에서 숨긴다.

- 홈은 새 여행·제작 중 여행·확정 패스를 카드 대시보드로 제공한다. 새 여행을 주요 카드로 강조하고 카드 전체를 하나의 링크로 사용한다.
- 방문객에게 본인의 제작 중·확정 개수와 최근 생성한 제작 중 여행 이름을 표시한다. 비로그인은 별도 랜딩을 제공하며 다른 역할에는 개인 카드를 숨긴다.
- 좁은 화면에서는 한 열로 전환한다. 방문객 흐름에서는 여행 구성·기록을 우선하고, 상품·시설·이용 방법·유의사항은 [투어패스 안내](#투어패스-안내), 내 이용권·사용 이력은 [내 투어패스](#내-투어패스)에 둔다. 여행 패스와 시연 혜택 이용권을 구분하고 시연 표시·추천 근거를 유지한다.

### 패스 목록·표지

- 내 여행은 사용 완료한 여행 기록만 표시하고 하위 탭은 두지 않는다. 제작 확정한 진행 중 여행은 내 투어패스에서 이용하며, 제작 중 목록은 여행 만들기에 둔다.
- 제작 중·진행 중 여행·여행 기록은 상태·이름·날짜·선택 카드 수를 구분한 가로형 패스를 공유한다. 여행 상세도 같은 표지를 사용한다.
- 선택 순서에서 사진이 있는 첫 카드의 이미지를 오른쪽에 배치한다. 사진이 없으면 단색으로 표시하고 제목·상태·날짜·동작은 불투명 표면에 둔다.
- 카드 전체를 누르면 제작 중은 이어 만들기, 확정·아카이브는 상세로 이동한다. 사용 완료한 여행에는 상태 동작을 두지 않고, 투어패스를 구매한 여행에는 제작 중으로 보내기를 두지 않는다. 별도 열기 버튼은 두지 않는다. 카드 전체에 키보드 포커스를 표시하고 삭제·출처 조작은 이동 링크와 분리한다.
- 삭제·사용 완료·제작 중으로 보내기는 정보 영역 오른쪽 위의 동작 아이콘과 확인 팝오버로 실행한다. 구성·사진 출처 버튼은 정보 영역 아래에 고정한다. 팝오버가 카드 크기를 바꾸거나 사진 위에 버튼이 겹치지 않게 한다.
- 팝오버 배치는 [공통 화면 틀](#공통-화면-틀)을 따르며 바깥 클릭으로도 닫는다. 사진 출처 항목과 이용 조건은 [이미지 기준](../data-collection/common.md#이미지)을 따른다.
- 방문객 홈과 제작 중 목록의 새 여행 만들기는 상품 선택 화면으로 이동한다. 전체 상품에서 상품으로 여행 시작과 직접 카드 고르기를 제공하고 별도 시작 구성 팝오버는 두지 않는다. 저장 시점·상품 시작 조건은 [여행 구성](../func-specs/02-visitor.md#여행-구성)을 따른다.

### 여행 만들기

[구성 단계](../func-specs/02-visitor.md#구성-단계)를 별도 화면으로 표시한다. 입력·저장 조건은 [여행 구성](../func-specs/02-visitor.md#여행-구성)을 따르며 삭제는 펼친 경고에서 확인 후 실행한다.

#### 탐색·선택

- 상단에 덱 구성·여행 확인의 현재 단계를 표시하고, 전환 시 화면 제목으로 포커스를 옮긴다. 단계별 선택·보존 조건은 [구성 단계](../func-specs/02-visitor.md#구성-단계)를 따른다.
- 덱 위에 여행 취향 선택과 카드 검색을 나란히 두고 지역·행사 날짜·동반 유형은 접힌 ‘세부 조건’에 둔다. 조건을 바꾸면 즉시 후보와 추천을 갱신한다. 추천 카드는 앞면 종류 옆에 ‘추천’을 표시하고 뒷면에 찾은 이유를 보여 준다.
- [이어 담기 기준](../func-specs/02-visitor.md#이어-담기)에 따라 기준 카드 이름과 정렬 방식을 안내하고, 담은 카드가 있으면 상품으로 시작했거나 이어 만드는 여행도 아직 담지 않은 가장 가까운 후보부터 보여 준다. 추천 순서와 ‘추천’ 표시는 담은 카드가 없을 때만 쓴다. 앞면에는 대표 지점 간 직선거리를 표시한다. 실제 이동거리와 다름을 설명하며 좌표가 없으면 미확인 또는 같은 지역 우선 안내를 표시한다.
- 가로 스크롤 스냅·터치 스와이프·마우스 드래그·이전/다음 버튼·방향키로 탐색한다. 중앙 카드와 양옆 카드의 크기·강조를 구분하고 중앙에서의 거리에 따라 회전·깊이를 바꾸되 모션 감소 설정에서는 끈다.
- 관광지·행사·음식점/카페는 같은 선택·상세·저장 조작을 제공한다. 카드 클릭으로 선택·해제하며 우측 상단 더하기를 체크로 바꾸고 초록 테두리·밝은 안쪽 선·접근성 선택 상태를 함께 갱신한다. 담으면 카드가 짧게 튀어 오르고 카드 사진을 담은 작은 원이 하단 시트의 작은 지도로 날아가며, 도착하면 선택 수가 짧게 커진다. 동시에 덱을 짧게 밀어내고 [이어 담기](../func-specs/02-visitor.md#이어-담기) 순서로 다시 놓으며 가장 가까운 후보를 보여 준다. 이때 정렬 기준 문구를 잠시 강조하고 ‘○○에서 가까운 순으로 다시 놓았어요’를 알린다. 동작 줄이기에서는 날아가는 효과 없이 짧은 페이드만 쓴다. 멈춰 기다리는 구간은 두지 않는다. 카드 섞기는 제공하지 않는다.
- 상세 버튼으로 카드를 뒤집고 다른 카드로 이동하면 앞면으로 복귀한다. 앞·뒷면 전환 버튼은 우측 하단에 두고 설명과의 간격을 좁힌다.
- 탐색 안내에서 관광지·행사·음식점/카페를 함께 고르는 흐름을 설명하고, 동반 유형 선택 바로 아래에 가족 체험의 조건 확인을 안내한다. 실제 관광지의 방문 전 확인 안내는 카드 뒷면·장소 상세·출력 QR 안내 페이지에서 같은 조각을 사용한다.

#### 카드 정보·사진

- 카드 앞면 상단에는 선형 아이콘과 종류를, 하단 흰 정보 패널에는 이름 → 위치·행사 날짜 → 구분선이 있는 상세 버튼을 배치한다. 검토 상태·출처·확인일·사진 이용 조건은 뒷면의 스크롤 영역에 제공한다.
- 세로형 비율은 [카드 방향](#카드-방향)을 따른다. 관광지 사진 배경에는 약한 틴트를 적용하되 종류·이름·위치·상세 버튼은 불투명 흰 표면과 진한 글자로 표시한다.
- 행사·음식점/카페 사진은 종류 배지와 정보 패널 사이 독립 영역에 배치한다. 표시·편집 허용 범위는 [행사](../data-collection/events-data.md#이미지)·[음식점 이미지 기준](../data-collection/dining-data.md#이미지)을 따른다. 사진이 없는 행사·음식점/카페·기존 가맹점은 같은 옅은 초록 바탕과 종류별 선형 그림을 사용하며 이미지 준비 문구는 표시하지 않는다.

#### 선택 목록·저장

- 덱 구성 중에는 하단 메뉴를 숨기고, 지도·담은 목록을 화면 폭과 관계없이 화면 아래 한 시트로 묶는다. 다른 화면으로는 상단 뒤로 가기로 이동한다. 접힌 시트는 한 줄로, 왼쪽에 회색 톤의 작은 지도(핀·순서 선은 색 유지), 가운데 선택 수, 오른쪽에 ‘여행 확인’을 둔다. 손잡이·작은 지도를 누르거나 끌어올리면 큰 컬러 지도와 담은 목록을 펼치고, 끌어내리기·바깥 누르기·Esc로 접는다. 지도·목록으로 키보드 포커스가 들어오면 펼친다. 단계가 바뀌면 접는다.
- 여행 확인은 탐색 보드와 시트를 숨기고 본문에 지도·전체 순서·이름·날짜·저장 동작을 표시한다.
- 지도는 담은 카드만 진한 번호 핀과 순서 선으로 표시하고 방금 담은 핀은 짧게 강조한다(동작 줄이기에서는 생략). 덱의 현재 카드가 담은 카드면 그 핀에 테두리를 둔다. 덱 구성의 핀을 누르면 해당 카드로 덱을 이동한다. 선택이나 지도 크기가 바뀌면 담은 카드 전체가 보이도록 맞추고, 표시할 핀이 없으면 덱 구성에서는 시흥 전체를 보여 주고 여행 확인에서는 지도를 숨긴다. 좌표 없는 카드 수는 지도 아래에 안내한다. 펼친 지도 높이는 좁은 화면 240px, 넓은 화면 320px이며 지도 출처를 지도 안에 표시한다. 지도를 불러오지 못하면 지도 영역을 숨긴다.
- 담은 목록은 여정 타임라인이다. 지도 핀과 같은 번호 원을 세로선으로 잇고 작은 사진(없으면 종류 그림)·이름·종류를 표시하며 첫 카드에 시작점을 표기한다. 두 번째 카드부터 앞 카드와의 대표 지점 간 직선거리를 표시한다. 순서 변경·빼기는 오른쪽의 테두리 없는 작은 아이콘 버튼으로 두고 긴 이름은 말줄임으로 표시한다.
- 여행 확인은 하단 메뉴를 다시 보이고 별도 이동 바 없이 ‘담은 카드’ 제목 옆에 ‘덱 수정’을 둔다.
- JavaScript가 없으면 카드 목록과 저장 폼을 모두 표시한다. 검토 대기 관광지의 담기·저장 조건은 [요구사항](../func-specs/02-visitor.md#여행-구성)을 따른다.

### 정보와 행동의 우선순위

- **시각적 위계:** 한 화면·단계는 하나의 핵심 작업에 집중하고 주요 행동 하나만 강조한다. 제목 → 필요한 정보·입력 → 실행 순서로 배치하며, 부가 설명·설정은 접어 둔다. 초기화·다른 대상 조회는 보조 동작으로, 삭제·취소는 위험 동작으로 구분한다.
- **일관성:** 공통 토큰·컴포넌트를 재사용하고 같은 기능의 배치·조작·상태 표현을 통일한다. 같은 대상과 행동에는 같은 용어를 쓰며, 버튼은 실행 결과를 알 수 있는 구체적인 동사로 표현한다. 기능별로 별도 스타일·표현을 만들기 전에 기존 기준을 확인한다.
- **유저 플로우 데드엔드 제거:** 정상 완료·빈 결과·실패·권한 제한·비활성 상태마다 이유와 가능한 다음 행동을 제공한다. 재시도·조건 초기화·이전 작업·대체 경로 중 상황에 맞는 조작을 바로 연결하고, 복구 과정에서 선택·입력을 가능한 한 보존한다. 접근할 수 없는 화면이나 같은 오류로 반복 안내하지 않는다.
- 여행 구성은 ‘여행 만들기·담은 카드’, 혜택 인증은 ‘혜택 이용권 코드’로 표현해 두 기능을 구분한다.
- 기록 입력을 먼저 보여주고 추천 반영 설명은 기본 접힌 안내로 제공한다. 유효기간·사용 차감 조건은 실행 전에 노출한다.
- 담당자의 혜택 사용 확인·사용 이력은 내용 높이에 맞춘 간결한 카드로 표시한다. 사용 이력에서 다음 코드 조회로 바로 연결하고, 방문객 피드백 화면은 혜택 사용 이력으로 돌아간다.
- 새 만족도는 미선택 상태에서 시작한다. 저장된 평가는 기존 선택을 유지한다.

### 여행 기록·상태 변경

- 사용 완료한 여행 상세는 표지 → `이렇게 다녀왔어요` 순서다. 날짜·지역·장소 수로 한 줄 요약하고 기록·사진 수와 사용한 투어패스 혜택 수를 덧붙인 뒤, 방문 순서대로 장소별 방문일·별점·메모·사진을 읽기 전용으로 보여 준다. 투어패스 패널·이름·날짜 변경은 두지 않는다.
- 장소마다 `기록 남기기`(기록이 있으면 `기록 수정`)를 접힌 영역으로 두고 펼치면 별점·방문 날짜·메모와 사진 한 장을 입력한다. 방문 날짜는 한국 시간 기준 오늘까지만 선택한다. 별점은 별 다섯 개를 눌러 고르고 `선택 안 함`으로 비운다. 방문 날짜가 비어 있을 때 별을 고르면 여행 날짜(미래면 오늘)로 채운다. 사진은 고르면 바로 올리며, JavaScript가 없으면 저장 버튼을 보인다. 저장 후 같은 장소로 돌아온다.
- 진행 중인 여행 상세는 방문 순서와 장소별 혜택만 보여 주고 `여행 마치고 기록 남기기` 하나를 주요 행동으로 둔다. 방문 날짜·만족도·메모·사진 입력은 사용 완료한 여행 상세에만 둔다. 사용 완료는 되돌릴 수 없음을 버튼 옆에 알리고, 완료 전 확인 팝오버에서 여행 이름과 이름·날짜 변경 및 환불이 제한됨을 확인한다. 닫으면 진행 중 상태를 유지한다.
- [허용된 상태 변경](../func-specs/02-visitor.md#저장과-상태-변경)은 패스의 상태 팝오버에서도 실행한다. 사용 완료로 바꾸면 그 여행의 기록 화면으로, 그 밖에는 해당 상태의 목록으로 이동한다.

### 여행 포토카드

사용 완료 여행의 상세에서 포토카드 보기로 연결한다. 관리자와 공통 출력 배치에 본인 사진·장소 이름·여행 이름·방문일을 표시하고 인쇄/PDF 저장을 제공한다. 사진이 없으면 기록 화면의 업로드로 안내한다. 업로드·조회 조건은 [여행 사진](../func-specs/02-visitor.md#여행-사진)을 따른다.

### 투어패스 안내

[이용권 기능](../func-specs/02-visitor.md#혜택-이용권)의 공개 안내에는 헤더 탭을 두지 않는다. 이용 가능 시설은 전체 상품의 "혜택 받는 곳 모아 보기"로 진입하고, 내 투어패스·이용권 상세·구매 화면의 가맹점 이름은 가맹점 상세로 연결한다. 이용 방법은 랜딩의 "이렇게 이용해요"와 방문객 홈의 접힌 이용 방법에, 투어패스 유의사항은 구매 화면의 "구매 전 확인"과 내 투어패스의 접힌 유의사항에, 여행 패스·장소 안내의 유의사항은 여행 상세의 기록 안내 문구에 둔다. 이전 `tab=usage`·`tab=notes` 주소는 전체 상품으로 보낸다. 전체 상품은 새 여행 만들기에서 진입한다. `/merchants?tab=facilities`가 이용 가능 시설이고 기본은 전체 상품이다. 이용 가능 시설의 뒤로가기는 전체 상품, 가맹점 상세의 뒤로가기는 이용 가능 시설로 간다.

- 전체 상품과 직접 카드 고르기는 기존 여행 패스 표지를 공유하고 사진을 오른쪽에 배치한다. 상품은 혜택 순서에서 사진이 있는 첫 장소를 표지로 사용하고, 직접 고르기는 탐색 가능한 장소 사진을 사용한다. 왼쪽에는 접어 펼치는 받을 수 있는 혜택과 여행 시작 동작 하나를 둔다. 상품 설명·사진 출처는 구성·출처 팝오버에 둔다. 목록·상세에 가격·구매 버튼은 두지 않으며 여행 확인·확정 여행의 구매 안내에서 제공한다. 여행 시작 불가 사유는 비활성 버튼 아래에 표시한다.
- 이용 가능 시설은 세로 카드에 가맹점 위치·제공 혜택을 표시한다. 여행 카드의 안내 장소와 혜택 가맹점을 구분한다.
- 이용 방법은 혜택 이용권·여행 패스의 두 단계 목록으로, 투어패스 유의사항은 [공통 정책](../func-specs/01-common.md#정책)을 확인할 목록으로 표시한다.

### 내 투어패스

`/passes`는 진행 중인 여행 → 접힌 유의사항 → 혜택 사용 이력 → 구매 내역 순서의 목록이다. QR·코드는 여기에 펼쳐 두지 않고 패스를 눌렀을 때 보여 준다. 진행 중인 여행을 누르면 여행 상세에서, 구매 내역을 누르면 이용권 상세(기간·상태·혜택 사용 내역)에서 확인한다. QR·코드는 진행 중인 여행 상세에만 표시한다. 이용권 상세에는 표시하지 않고, 진행 중인 여행에 연결된 이용권이면 `코드·QR 보기`로 그 여행에 연결한다. 사용 이력에는 피드백 버튼을 제공한다. 환불할 수 있는 이용권은 코드 아래(여행 상세)와 이용권 상세에 보조 버튼 `환불하기`를 두고, 금액과 되돌릴 수 없음을 알리는 확인 팝오버를 거쳐 실행한 뒤 이용권 상세로 이동한다.

### 여행과 투어패스

- 혜택이 있는 카드는 앞면 정보 패널에 `투어패스 · 혜택명` 배지를 표시한다. 연결된 투어패스가 있으면 배지에 사용 가능·사용 예정·사용 완료 상태를 덧붙인다.
- 여행 확인 단계는 이름·날짜 입력 아래에 추천 투어패스(상품명·혜택 장소 수·가격)를 표시한다. 추천이 있으면 `확정하고 투어패스 구매`를 주요 버튼, `구매 없이 여행 확정`을 보조 버튼으로 두고, 없으면 `여행 확정`을 주요 버튼으로 둔다. `임시 저장`은 항상 보조 버튼으로 제공한다.
- 여행 상세는 표지 아래에 연결된 투어패스(상품·상태·시작 시각·기간, 진행 중이고 사용할 수 있으면 남은 시간·QR·코드) 또는 [추천 상품](../func-specs/02-visitor.md#혜택-이용권)을 한 패널로 표시한다. 추천 패널의 주요 행동은 `가격 · 구매하기` 버튼 하나다. 이름·날짜 변경은 그 아래 접힌 설정에 둔다.
- 구매 화면(`/passes/checkout`)은 여행 이름·상품·이용 일정·포함 혜택(장소별 본인 부담·예약 조건) → 결제 금액·결제 버튼 순서로 배치한다. 이용 기간이 겹치면 구매 불가 사유와 내 투어패스 확인을 제공하고, 진입한 여행 또는 상품으로 돌아가는 링크를 둔다. 시연 결제임을 버튼 아래에 표시한다. 결제 후 여행에서 왔으면 여행 상세, 아니면 내 투어패스로 이동한다.

### 상세·혜택

- 관광 카드 상세는 사진·소개, 위치·방문 조건, 출처 순서로 읽으며 관리자는 상단에서 편집·출력한다.
- 혜택은 본인 부담·할인을 먼저, 위치·예약 조건을 다음으로 표시한다. [이용권 기간](../func-specs/01-common.md#정책)과 코드 제시·담당자 확인·사용 후 평가 흐름, 내 투어패스 진입점을 제공한다.

## 플로팅 필 탭 바

- 하단 메뉴는 화면 가장자리에서 띄운 불투명 캡슐로 표시한다. 메뉴 외곽·선택 배경·hover는 같은 `--radius-pill` 토큰을 사용한다.
- 아이콘·한 줄 라벨을 중앙 정렬하고 선택 배경은 둘을 함께 감싼다. 현재 메뉴는 브랜드 색상·배경·굵기로 구분하며 상단 표시선은 쓰지 않는다.
- 본문 여백과 기기 안전 영역을 확보해 본문·포커스를 가리지 않는다. 여행 만들기의 덱 구성 중에는 표시하지 않는다([선택 목록·저장](#선택-목록저장)). 키보드 포커스는 메뉴 안쪽에 표시한다.
- 공통 규격 변경 시 기능별 카드의 비율·동작과 대화상자의 곡률을 유지한다.

하단 고정 작업 버튼은 필 형태의 플로팅 버튼 바로 표시한다. 밝은 바 표면과 흰 보조 버튼·기존 강조색의 주 버튼을 사용하며, 공통 여백 토큰과 바깥쪽의 넓고 부드러운 그림자로 층을 구분한다. 단일·복수 버튼 모두 필 곡률을 사용하고 가장자리 여백·안전 영역·본문 공간을 확보한다. 내비게이션과 함께 보이면 그 위에 간격을 둔다.
