# 행사 데이터

[행사 데이터](../backend/data/siheung-events.json)에 공식 안내의 일정·장소·비용·예약 조건·출처와 이미지 메타데이터를 보존한다. 전체 시흥 행사 목록이 아닌 가을 행사 표본이며, 행사 목록과 미확보 항목은 JSON에서만 관리한다.

## 사용 기준

- 공개·여행 담기 정책은 [기능 16](../spec.md#기능)을 따른다. 원본은 JSON으로 유지하고 개인 여행에는 이름·장소 등의 스냅샷을 저장한다. 검토 대기인 행사·장소 연결·이미지는 `DRAFT`로 두며 검토자·승인 시각을 추정하지 않는다. 일반 수집·승인 원칙은 [관광 데이터](tourism-data.md)를 따른다.
- `date_position_on_checked_on`은 확인일 기준 달력 분류로, 실제 개최·취소 여부가 아니다. 화면 분류는 기능 16에 따라 현재 한국 날짜로 다시 계산하고 공식 운영 안내를 재확인한다.
- `null`·`UNKNOWN`은 미확인이다. 참가자 비용을 일반 관람료로, 일부 프로그램 시간을 전체 운영시간으로 확대하지 않는다. 출처의 접수 요일 오기와 시간표 불일치는 해당 출처·행사에 기록했다.
- 기존 관광 장소와의 연결은 서비스 분류인 `PROJECT_CLASSIFICATION`이다. `VENUE`는 동일 장소, `RELATED_AREA`는 관련 지역이며 정확한 행사장 일치를 뜻하지 않는다.

## 이미지

[공통 이미지 기준](tourism-data.md#이미지)을 적용한다. [원본 이미지](../backend/data/event-images)는 변환하지 않고 보존하며 JSON의 원본 URL·출처 페이지·이용 조건·SHA-256으로 대조한다.

경기도청 사진은 공공누리 제3유형, 시흥시·시흥문화예술 공식 블로그 홍보물은 CC BY-NC-ND 2.0 KR 표시와 행사 대응을 확인했다. 블로그 홍보물은 비영리 용도로만 사용한다. `PAGE_LICENSE_CHECKED`이고 로컬 파일이 있는 사진만 배포한다. 원본 비율로 전체를 보여 주며 크롭·필터·문구 합성을 하지 않는다.

재사용 조건이 미확인인 홍보물은 원본 URL만 수집하고 파일 다운로드·화면 노출을 보류한다. 허락 또는 명시적 개방 조건 확보 후 재개한다. 강연 2건은 해당 강연이 함께 실린 공식 프로그램 안내를 연결하고 공통 자료임을 표기한다. 세계커피콩축제는 해당 연도 공식 부대행사 세계커피대회 안내 이미지를 사용하고 부대행사 자료임을 표기한다.
