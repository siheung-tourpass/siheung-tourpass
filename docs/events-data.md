# 행사 수집 자료

[행사 데이터](../backend/data/siheung-events.json)에 공식 안내의 일정·장소·비용·예약 조건·출처와 이미지 메타데이터를 보존한다. 전체 시흥 행사 목록이 아닌 가을 행사 표본이며, 행사 목록과 미확보 항목은 JSON에서만 관리한다.

## 사용 기준

- `/events`와 새 여행 화면에서 검토 상태를 표시하는 안내 자료로 공개한다. 행사 원본은 JSON으로 유지하며 개인 여행에는 이름·장소 등의 스냅샷을 저장한다. 행사·장소 연결·이미지의 `DRAFT`를 유지하며 검토자·승인 시각을 추정하지 않는다. 일반 수집·승인 원칙은 [관광 데이터](tourism-data.md)를 따른다.
- 일정의 종료일은 포함하며 한국 시간으로 해석한다. `date_position_on_checked_on`은 확인일 기준 달력 분류로, 실제 개최·취소 여부가 아니다. 노출 시 현재 날짜로 다시 계산하고 공식 운영 안내를 재확인한다.
- `null`·`UNKNOWN`은 미확인이다. 참가자 비용을 일반 관람료로, 일부 프로그램 시간을 전체 운영시간으로 확대하지 않는다. 출처의 접수 요일 오기와 시간표 불일치는 해당 출처·행사에 기록했다.
- 기존 관광 장소와의 연결은 서비스 분류인 `PROJECT_CLASSIFICATION`이다. `VENUE`는 동일 장소, `RELATED_AREA`는 관련 지역이며 정확한 행사장 일치를 뜻하지 않는다.

## 이미지

[원본 이미지](../backend/data/event-images)는 파일을 변환하지 않고 보존했다. JSON의 원본 URL·출처 페이지·이용 조건·SHA-256으로 대조한다. 촬영자·촬영일 미확인 사진을 해당 연도 개최 현장의 증거로 사용하지 않는다.

경기도청 게시물의 사진은 공공누리 제3유형 표시와 행사 대응을 확인했다. `PAGE_LICENSE_CHECKED`이고 로컬 파일이 있는 사진만 배포한다. 출처·유형·원문 링크를 표시하고 원본 비율로 전체를 보여 주며 크롭·필터·문구 합성을 하지 않는다. 게시물의 제공기관과 개별 촬영자는 구분한다.

시흥시 공식 블로그의 홍보물은 원본 URL만 수집했다. 재사용 조건이 확인되지 않아 파일 다운로드·화면 노출은 보류하며, 허락 또는 명시적 개방 조건 확보 후 재개한다. 미확보 행사에 다른 행사 사진이나 생성 이미지를 대신 넣지 않는다.
