# 음식점·카페 데이터 — 시흥 투어패스

[문서 안내](../../README.md#관련-문서) · [데이터 수집 공통 기준](common.md)

[수집 자료](../../backend/data/siheung-dining.json)에서 시흥시 공식 지정 업소 표본과 출처(`sources`)를 관리한다.

## 원본·공개 기준

- 업소명·주소·업태·지정번호·지정일은 공식 사실이며, 카페 구분·검색 지역은 서비스 분류다([공통 원본 기준](common.md#원본)의 `checkedOn`·`contentDate` 기록).
- 공식 지정 근거(`SOURCE_CHECKED`)가 있는 업소만 공개하고 취소 업소는 제거하되 기존 여행 스냅샷·기록은 보존한다(코드 재사용 금지).
- 영업시간·가격·예약·현재 영업 여부는 `미확인`으로 표시하며, 여행·혜택 연결은 [여행 구성](../01-func/02-visitor.md#여행-구성)을 따른다.

## 이미지

[공통 이미지 기준](common.md#이미지)(공공누리 제3유형 변경 금지 포함)을 충족한 사진만 등록하며, 미확보 후보 조사는 [이미지 조사](dining-images.md)에서 관리한다.

## 배포

WAR에 포함되며 JSON·이미지 변경 시 재빌드한다([시작하기](../../README.md#시작하기)).
