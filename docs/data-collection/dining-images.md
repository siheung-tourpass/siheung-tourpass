- 한국관광공사 콘텐츠랩(`hub/getTourDbInfo.do`, `com/getImage.do`)에서 위 5개 업소의 시흥 지점 사진을 찾지 못했고, [공유마당 보리굴비 사진](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200018&wrtSn=13276201)(CC BY)은 해당 업소 촬영 근거가 없어 제외했다.
