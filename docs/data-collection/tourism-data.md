# 관광 데이터

## 원본

[siheung-tourism.json](../../backend/data/siheung-tourism.json)의 `sources`·`source_ids`에 출처·근거를 둔다. 장소 목록·건수·추천 예시는 JSON만 갱신한다.

관광 자료의 적재·검토·사진 배포를 다룬다. 출처·좌표·이미지의 공통 원칙은 [데이터 수집 공통 기준](common.md)을 따른다.

- 사실 요약 `SOURCE_FACT`, 서비스 분류 `PROJECT_CLASSIFICATION`, 자체 개념 `PROJECT_MODEL`을 구분한다. 실제 자료는 `REAL`, 자체 테마 부모는 `DEMO`·`PROJECT_MODEL`; 실제 가맹점·혜택 연결은 없다.
- 지역은 행정구역이 아닌 검색 분류. 장소당 지역 1개, `region_code`와 `locatedIn` 일치, `전체` 미저장. 표시명 변경 시 코드 유지·시연 ID와 분리.
- `source_ids`는 같은 파일의 `sources.code` 참조이며 적재 시 출처 메타데이터로 해석한다. 확인일은 `checked_on`, 원문 기준일은 `content_date`에 기록한다.
- 관광 소개 출처의 원문·이미지·음성은 복제하지 않으며 사진은 별도 [이미지 기준](#이미지)을 따른다.

## 적재

### 최초 적재

초기 적재 명령과 DB 마이그레이션은 [README](../../README.md#시작하기)를 따른다. 기존 시연 DB에 실제 자료를 아직 적재하지 않았다면 백업 후 README의 **실제 관광 자료 생성·적재 명령 두 줄만** 1회 실행한다. 이미 적재한 자료는 재적재하지 않고 관리자 화면에서 근거·확인일을 갱신한다.

모든 장소·개념·관계는 `DRAFT`, 검토자·시각은 `null`로 적재한다. `active=true`는 승인·영업을 뜻하지 않는다. 관리자가 장소와 관계를 각각 승인하기 전에는 추천에서 제외한다. 의미 자료를 수정하면 다시 검토한다.

### 추가 적재·시연 자료 전환

이미 실제 자료가 있는 DB에 새 장소만 추가하려면 README의 관광 SQL 생성 명령에 `--place-code 장소코드`를 필요한 만큼 반복한다. 코드는 JSON에서 확인하며 아직 적재하지 않은 장소만 지정한다. 기존 장소의 승인·수정 내용은 덮어쓰지 않으며, 중복 적재는 트랜잭션 전체가 실패한다.

`--replace-demo`는 가상 장소와 시연 빈 지역을 비활성화하며 기존 여행·발급·사용 기록을 삭제하지 않는다. 테스트에서는 옵션 없이 가상 후보를 유지한다. 출처에 기록된 주소는 위치 설명으로 적재하며 상세 주소가 없는 장소는 `상세 주소 미확인`을 표시한다.

## 검토

- 개별 출처의 과거 일정·주소 불일치·운영 조건 미확인 사항은 [수집 자료](../../backend/data/siheung-tourism.json)의 출처·장소·관계 근거에서 확인한다. 과거 소개와 프로그램을 현재 운영 조건으로 사용하지 않는다.
- 장소·관계의 근거와 확인일을 각각 검토한다. 대표 주소·좌표를 전체 경계·개별 시설·진입점으로 확대하지 않는다.
- 추가 장소는 공식 소개·위치·관계 근거를 확보한 뒤 같은 형식으로 등록한다. 수집 자료는 시흥 전체 관광지·수요의 대표 표본이 아니다.

### 방문 조건

- 공식 운영기관 자료로 운영시간·이용료·예약/접수·주차와 진입 방법·야간 개방 및 조명 안내를 확인한다. 가족 체험은 대상 연령·보호자 동반·운영 기간을 함께 확인한다.
- 확인된 내용은 기존 소개·근거 요약에 출처·확인일과 함께 반영한다. 자료가 없으면 미확인으로 남기고 방문 전 공식 안내 확인을 유도한다. 주차 가능·야간 안전·아동 적합성을 지리적 근접성이나 테마로 추정하지 않는다.
- 지역 문제 게시글은 조사 질문의 출처로만 사용한다. 특정 장소의 현재 운영 조건이나 추천 관계를 승인하는 근거로 사용하지 않는다.

## 이미지

[공통 이미지 기준](common.md#이미지)에 따라 등록한다. 아래는 관광 사진의 배포·편집 조건이다.

[이미지 메타데이터](../../backend/src/main/resources/place-images.json)와 [정적 자산](../../frontend/assets/places)을 함께 배포하며 장소 코드로 연결한다. 사용자 요청마다 외부 이미지를 호출하지 않는다. Wikimedia Commons의 개별 라이선스 사진과 공공기관이 공공누리 제1유형으로 개방한 사진을 사용한다.

공공누리 사진은 로그인 없이 공개된 미리보기만 수집한다. 별도 신청이 필요한 고해상도 원본은 수집하지 않는다. 일반 상세는 전체를 비율대로 축소하고 여행 카드 배경·패스 표지는 표시 영역에 맞춰 크롭·틴트를 적용한다. 원본 파일은 보존한다.
