# 데이터 수집 공통 기준

관광·행사·음식점 자료의 출처·좌표·이미지에 적용한다. 자료별 검토·공개·배포 조건은 [관광](tourism-data.md)·[행사](events-data.md)·[음식점](dining-data.md) 문서에서 관리한다.

## 원본

- 출처 URL·원문 기준일·확인일·근거는 각 수집 JSON에서 관리한다. JSON에 있는 대상 목록·건수·개별 조사 결과는 문서에 복제하지 않는다. 미등록 사진 후보의 근거·보류 사유는 [음식점 이미지 조사](dining-images.md)에서 관리한다.
- 원문 확인일과 원문 자체의 기준일을 구분한다. 기준일이 없으면 미확인으로 남긴다.
- 사실과 서비스 분류를 구분하고, 특정 시설·구간·프로그램의 근거를 전체 장소·행사·시흥시의 특성으로 확대하지 않는다.
- 주소·운영·가격·예약·좌표 등 근거 없는 값은 `null`·`UNKNOWN`으로 둔다. 검토자·승인 시각도 추정하지 않는다.

## 좌표

관광 자료의 `operational.coordinates`, 행사·음식점 자료의 `coordinates`에 WGS84 위도·경도·출처·확인일·대표 지점 근거를 둔다. 한국관광공사 지도와 카카오맵의 장소명·주소를 대조하며, 넓은 관광지·행사장의 점은 출입구나 무대 위치를 보장하지 않는다. 시연용 허구 장소와 공개되지 않은 저장 카드는 실좌표를 부여하지 않는다. 좌표는 WAR에 포함하고 런타임 외부 지도 호출 없이 [CardCoordinates](../../backend/src/main/java/kr/ac/siheung/tourpass/service/CardCoordinates.java)가 카드 코드로 연결한다.

## 이미지

- 실제 장소·촬영 대상과 원본 설명 페이지의 재사용 조건을 대조한 사진만 등록한다. 게시물의 이용 조건이 사진에도 적용되는지 확인하며 제3자 사진 제외·텍스트 한정 허용 자료는 사용하지 않는다.
- 원본 파일과 대체 텍스트·저작물명·제공기관·촬영자·출처 페이지·공개 이미지 URL·라이선스·확인일·검토 근거를 보존한다. 촬영자·촬영연도는 확인된 경우만 기록하고 제공기관·게시일과 구분한다.
- 화면에는 촬영자·촬영/게시 날짜·출처·라이선스·편집 여부를 표시한다. 사진은 현재 운영·개최 상태의 증거가 아니며 사진 등록은 장소·관계의 추천 승인을 대체하지 않는다.
- 미확보 대상에 다른 장소·행사 사진이나 생성 이미지를 대신 쓰지 않는다. 관광 추천·장소 상세는 사진 준비 중으로 표시하고, 탐색 카드의 대체 표시는 [디자인 기준](../design.md#카드-정보사진)을 따른다.

변경 금지 사진은 원본 비율로 전체를 표시하며 크롭·틴트·필터·문구 중첩을 하지 않는다. 자료별 허용 범위와 배포 조건은 [관광 사진](tourism-data.md#이미지)·[행사 이미지](events-data.md#이미지)·[음식점 이미지](dining-data.md#이미지)를 따른다.
