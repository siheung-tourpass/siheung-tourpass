# 투어패스 시연 자료 — 시흥 투어패스

[문서 안내](../../README.md#관련-문서) · [공식 지정 음식점·카페](dining-data.md) · [공통 요구사항](../01-func/01-common.md#범위)

[시연 자료](../../backend/data/siheung-tourpass.json)는 실제 관광지·음식점·카페 카드에 연결하는 공모전 시연용 가상 가맹점·상품이다.

## 구성

- 가맹점은 관광지(`place`) 또는 음식점·카페(`dining`) 코드 1개와 혜택 1개(할인은 기준 금액·할인액 병기)를 가지며 이름·위치는 연결 카드에서 가져온다.
- 상품은 가격(`price_won`)과 포함 가맹점 목록(`ALL`은 전체 가맹점)을 가진다.

## 적재

관광 자료 적재 후 `python3 backend/scripts/tourpass-sql.py` 출력을 적용한다([시작하기](../../README.md#시작하기)). 기적재 DB는 백업 후 다시 적용하면 새 코드의 가맹점·상품·혜택만 추가되고, 이미 있는 코드는 관리자 화면의 수정 내용을 유지한다. 새 가맹점이 관광지 카드에 연결되면 해당 장소를 먼저 [추가 적재](tourism-data.md#추가-적재시연-자료-전환)한다. 초기 시연 상품·가맹점 A/B는 비활성화되며, 기록까지 삭제할 때만 [가상 자료 삭제 SQL](../../backend/sql/remove-demo.sql)을 실행한다(자동 검사 DB 제외).
