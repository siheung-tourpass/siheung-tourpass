# 투어패스 시연 자료 — 시흥 투어패스

[문서 안내](../../README.md#관련-문서)

[시연 자료](../../backend/data/siheung-tourpass.json)는 공모전 시연용 가상 가맹점·상품이다. 실제 관광지와 [공식 지정 음식점·카페](dining-data.md) 카드에 연결하지만 실제 제휴·가격·혜택이 아니며, 화면은 [공통 요구사항](../func-specs/01-common.md#범위)의 시연 표시를 따른다.

## 구성

- 가맹점은 관광지 코드(`place`) 또는 음식점·카페 코드(`dining`) 하나와 혜택 하나를 가진다. 이름·위치는 연결한 카드 자료에서 가져온다.
- 상품은 가격(`price_won`)과 포함 가맹점 목록을 가진다. `ALL`은 모든 가맹점을 포함한다.
- 할인 혜택은 기준 금액과 할인 금액을 함께 적는다. 값은 시연용이며 실제 메뉴 가격을 뜻하지 않는다.

## 적재

관광 자료를 적재한 뒤 `python3 backend/scripts/tourpass-sql.py` 출력을 한 번 적용한다. 명령은 [README](../../README.md#시작하기)를 따른다. 적재하면 초기 시연 상품과 가상 가맹점 A/B를 비활성화하며 기존 발급·사용 기록은 보존한다. 가상 자료와 그 기록까지 지우려면 백업 후 [가상 자료 삭제 SQL](../../backend/sql/remove-demo.sql)을 한 번 적용한다. 자동 검사용 DB에는 적용하지 않는다. 같은 DB에 다시 적용하면 코드 중복으로 전체가 실패한다. 이미 적재한 값은 관리자 혜택 관리에서 고친다.
