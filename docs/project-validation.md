## 검증 과제

참여자 구성·화면 제시 순서는 [완료 기준](../spec.md#완료-기준)을 따른다. 동일한 자료와 과제를 사용하고 개별 안내 화면/패스 화면의 결과를 구분한다. 가족 시나리오 수행 경험을 기록하되 실제 가족 사용성 검증과 구분한다.


| 과제                                         | 관찰·질문                                                                                                                         |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 갯골 등 관광지 한 곳에서 시작해 여행 구성    | 처음 알고 있던 장소와 새로 발견한 후보를 구분해 말하게 한다. 추가 카드를 발견·선택했는지와 종류를 기록한다.                       |
| 선택한 장소와 함께 갈 행사·음식점/카페 비교 | 후보의 위치·출처를 찾고 선택 이유를 설명하게 한다. 직선거리를 실제 이동거리·시간으로 오해하는지 확인한다.                        |
| 아이와 함께 가는 상황으로 후보 탐색          | 동반 유형·추천 이유·행사 날짜를 찾게 한다. 추천만으로 안전·연령 적합·접수 가능을 보장한다고 이해하는지 확인한다.               |
| 주차 또는 야간 이용 조건 확인                | 공식 출처·확인일·미확인 조건을 찾고 방문 전에 어디서 무엇을 확인할지 설명하게 한다. 정보 없음과 이용 불가를 구분하는지 확인한다. |
| 음식점 안내와 혜택 상세 비교                 | 위치·비용·예약 조건을 찾게 한다. 공식 지정 업소에 자동으로 할인·제휴가 있다고 오해하는지 확인한다.                              |
| 여행 후 메모 저장·보관·재조회              | 기억에 남는 경험을 메모하고 아카이브에서 다시 찾게 한다. 여행 기록과 혜택 피드백의 차이를 설명하게 한다.                           |
| 관리자가 출력한 카드의 QR로 장소 다시 찾기   | 관리자 출력 후 휴대전화로 공개 안내·출처를 열게 한다. 개인정보 노출 없이 다른 여행 카드 탐색으로 이어지는지 확인한다.             |

과제마다 익명 참여자 번호·시나리오·제시 순서·완료 여부·소요 시간·도움 요청·오해·수정 후 재검증 결과를 기록한다. 추가 장소 선택 수와 QR 접속 성공은 관찰 결과이며 실제 방문·소비·재방문의 증거로 해석하지 않는다. 종료 시 다시 이용할 의향은 주관적 응답으로 별도 기록한다.

## 대기 조건

참여자와 최신 공식 운영 자료 확보가 필요하다. 확보 후 위 과제와 [방문 조건 검토](data-collection/tourism-data.md#방문-조건)를 수행한다. 체류시간·실제 재방문·매출 효과는 현 범위의 화면 검사만으로 확인할 수 없으므로 측정값을 추정하지 않는다.
