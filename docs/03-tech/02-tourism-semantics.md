# 추천 모델 — 시흥 투어패스

[문서 안내](../../README.md#관련-문서) · [방문객 요구사항](../01-func/02-visitor.md#추천피드백) · [관광 데이터](../data-collection/tourism-data.md) · [기술 구조](01-architecture.md#기능별-구현-경계)

## 계층

- 어노테이션: 장소·관계의 실제/시연 구분·출처·확인일·근거·검토 상태.
- 온톨로지: 장소·지역·테마·동반 유형 관계와 상위 테마 추론(관계 부재는 정보 없음이며 테마로 안전·가격·예약을 추론하지 않음).
- 시맨틱 레이어: 승인된 관계 필터·순위·추천 이유·개인 보정.

## 계산

입력·피드백 조건은 [방문객 기능 4·6](../01-func/02-visitor.md#추천피드백), 후보 승인 조건은 [관광 데이터 적재](../data-collection/tourism-data.md#적재)를 따른다.

| 단계 | 계산·처리 |
| --- | --- |
| 기본 점수 | 선택 테마 일치당 2점 + 동반 일치 1점 |
| 개인 보정 | 적용 대상 평가의 `(만족도 − 3)` 평균(평가 없으면 0) |
| 정렬 | `기본 점수 + 개인 보정` 내림차순 → 장소 ID 오름차순 |
