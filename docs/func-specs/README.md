# 기능 명세 — 시흥 투어패스

공통 문서를 먼저 읽고 작업 대상의 역할 문서를 확인한다. 제품 범위·공통 정책·역할 간 상태 전이·전체 완료 기준은 공통 문서에서, 역할별 기능·조작·권한은 역할 문서에서 관리한다.

| 구분 | 문서 | 담당 내용 |
| --- | --- | --- |
| 공통 | [공통 요구사항](01-common.md) | 제품 범위·공통 정책·동작 계약·완료 기준 |
| 역할 | [방문객 요구사항](02-visitor.md) | 탐색·이용권·여행·추천·피드백 |
| 역할 | [가맹점 담당자 요구사항](03-merchant.md) | 혜택 확인·사용 |
| 역할 | [관리자 요구사항](04-admin.md) | 자료 관리·통계·카드 출력 |

구현 구조·검증 방법·남은 작업은 [구현 계획](../tech-specs/01-plan.md)을 따른다. 완료 기준은 수용 조건이며 검증 완료 기록이 아니다.
