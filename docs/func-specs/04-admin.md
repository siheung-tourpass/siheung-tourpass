## 관리자 작업과 카드 출력

### 자료 관리

- 관광지는 편집·검토할 수 있으며 행사·음식점·카페는 공개 안내만 확인한다. 수집 자료를 화면에서 수정하는 기능은 제공하지 않는다.
- 혜택 관리는 상품·가맹점·연결 혜택을 대상으로 한다. 가상 가맹점은 실제 관광지 또는 공식 지정 음식점·카페 카드 하나에 연결하며, 상품 가격과 혜택 조건은 시연용으로 정한다.
- 홈·메뉴·대상 선택·편집·출력 흐름은 [관리자 화면 기준](../tech-specs/02-design.md#관리자)을 따른다.

### 카드 출력

- 관리자만 공개 관광지·행사·음식점/카페를 선택해 사진과 안내 QR을 함께 담은 90×130mm 포토카드를 제작한다. 선택 문구 40자·동일 카드 1~4장을 A4 인쇄/PDF 저장용으로 미리 본다. 제작 설정은 저장하지 않는다.
- QR은 지정한 서비스 기본 URL의 비로그인 대상 안내 페이지로 연결한다. 이용권 코드·개인정보·인증 기능은 포함하지 않는다. 접속 주소 설정·출력 절차는 [사용 방법](../../README.md#사용-방법)을 따른다. 비공개로 전환된 대상은 안내 조회를 거부한다.
- 사진 이용 기준은 [관광](../data-collection/tourism-data.md#이미지)·[행사](../data-collection/events-data.md#이미지)·[음식점](../data-collection/dining-data.md#이미지)을 따른다. 사진이 없으면 문자형 카드로 제공한다. 비영리 제한 사진을 포함할 수 있으므로 출력은 비영리 안내용이다.

## 관광지 피드백 통계

| ID | 구현 조건 |
| --- | --- |
| 3 | 통계 메뉴에서 관리자만 관광지별 응답 수·평균 만족도(소수 첫째 자리)·1~5점 분포를 조회한다. |

- 응답은 방문객별 현재 평가를 집계하며 수정·삭제를 즉시 반영한다. 비활성·검토 상태 변경 후에도 남아 있는 평가를 포함한다.
- 응답 없는 관광지는 집계 목록에서 제외하며 전체 응답이 없으면 빈 상태를 안내한다. 작성자·의견 원문·개별 응답은 공개하지 않는다. 자가 보고 평가이므로 방문 인증 통계로 표현하지 않는다.
